# 테마 미리보기 적용 — 2026-09-23

사용자가 [테마 미리보기·확장 조사](THEME_PREVIEW_REVIEW_2026-09-23.md) 후 ‘진행’을 승인했다. 이번 범위는 **기존 A ‘시간 중심’의 미리보기·적용/취소와 확장 기초**다. 계절별 신규 디자인이나 다른 레이아웃 자체는 아직 추가하지 않았다.

## 사용자가 보게 되는 변화

- 설정의 화면 섹션에서 디자인 이름, 현재 화면 모드·색상, 오늘의 실제 남은 시간과 눈금 견본을 보여준다. ‘미리보기 및 변경’으로 전용 화면에 들어간다. 눈금 숨김 설정을 따른다.
- 시스템/밝게/어둡게 모드와 기존 6개 색상을 비교한다. 시스템 선택에는 현재 기기 밝기를 알려준다. 앱의 강제 밝기와 기기 밝기를 구분해 미리보기에 반영한다.
- 앱/위젯 보기를 전환한다. 앱은 실제 홈의 기간 요약·대표 시간·다음 시간 구간·날짜 일정·빈 상태를 재사용한다. 위젯은 기존 일반/기간 요약 렌더러를 대표 크기 320×200dp·320×96dp로 보여준다. 설치된 각 위젯의 내용·크기를 그대로 복제하는 기능은 아니다.
- 비교하는 동안 실제 데이터 스냅샷과 위젯 기준 시각을 고정하고 안내 문구를 표시한다. 등록 일정이 없으면 실제 오늘/달/년과 빈 상태를 표시한다. 위젯 단일 견본은 대표 일정이 없으면 오늘을 사용한다.
- 하단의 적용·취소는 스크롤과 분리한다. 다른 모드·색상 선택은 미리보기 안에서만 바뀌며 적용 전에는 전역 야간 모드·저장값·설치 위젯을 변경하지 않는다. 뒤로·취소는 임시 선택을 버린다.
- 변경이 있을 때 적용 버튼이 활성화된다. 모드·색상을 기존 두 키에 한 번의 편집으로 함께 저장하고 기존 위젯 갱신 경로를 한 번 호출한다. 기본 정렬·만료 처리·알림 드롭다운과 진행률 스위치는 유지한다.

## 코드와 상태 경계

- `ThemePreviewViewModel`은 저장소에서 한 번 읽고 기존 계산기로 화면 데이터를 만든다. 기존 홈 ViewModel은 반복 날짜 저장·알림 재예약을 수행하므로 미리보기에서 재사용하지 않는다. 반복 날짜는 기존 `forWidgetPreview()`의 복사본만 계산한다. 읽기 실패는 오류·다시 시도로 처리하며 빈 목록으로 위장하지 않는다.
- `rememberSaveable`로 진입 상태와 모드·색상·앱/위젯 선택을 복원한다. 회전 시 ViewModel의 스냅샷은 유지되고 프로세스 재생성 시에는 다시 읽는다. 미리보기를 새로 열거나 조회를 재시도할 때만 새 스냅샷을 요청한다.
- `HeaderSection`, `NextCountdownHero`, `TimeLeftItemCard`, `EmptyItemState`에 읽기 전용 표시를 추가했다. 기본값은 기존 동작 유지이며 미리보기만 상세·편집·삭제·위젯 추가·추가 버튼과 행동 힌트를 제거한다. 기간·일정의 숫자/눈금/날짜 표현을 복사하지 않는다.
- `WidgetPreviewBand`를 위젯 설정과 공유한다. 테마 미리보기의 네이티브 내용에서는 클릭·초점 동작을 제거하고 읽기 전용 설명을 제공한다. 표시가 불가능한 크기에는 기존 확대 안내와 같은 접근성 설명을 사용한다. 좁은 화면에서 축소하지 않고 가로 스크롤을 안내한다.
- `ThemeSelection`은 모드·팔레트 선택, `ThemeDefinition`은 A의 ID·정의 버전·지원 색상·서체·모양·색상 해석, `ResolvedTheme`은 해석 결과를 담당한다. 앱·임시 미리보기·위젯 팔레트가 같은 해석기를 사용한다. 정의 ID/버전을 생성 위젯 미리보기 캐시 식별에 포함했다.
- 새 디자인 저장 키나 DB 변경은 없다. 사용자 설정 키, 설치 위젯 ID/내용 선택, 4×2·4×1 크기 기준, 계산·알림 로직을 유지한다. **적용 시 기존 위젯 갱신에 따른 반복 일정 처리 등은 기존 경로대로 발생할 수 있다.** 미리보기·취소에서 그러한 경로를 호출하지 않는 것이 이번 변경의 경계다.
- 테마 정의는 확장의 기초다. 간격·움직임·눈금 토큰은 아직 기존 공통 규칙이고, 위젯 배경도 기존 밝게/어둡게 drawable을 사용한다. 계절 테마는 전체 색상/위젯 표면을, 다른 레이아웃은 실제 표현을 추가해야 한다. 지원하지 않는 디자인을 선택 목록에 미리 넣지 않았다.

## 확인한 범위

소스에서 임시 선택·적용 콜백, 읽기 전용 데이터 조회, 기존 설정 키/렌더러 호출 연결을 검토했다. 한/영 XML 구문·중복 이름·설정/테마 리소스 참조 62개·테마 문자열 19개의 언어/포맷 인자 대응, 변경 공백을 정적으로 확인했다. 실행을 통한 상태 검증과는 구분한다.

**사용자 지시에 따라 빌드·Lint·단위 테스트·새 APK 설치·실화면 검수는 실행하지 않았다.** 현재 설치 앱에 이번 코드가 포함됐다고 간주하지 않는다. 새 기준의 전후 캡처는 없으며 최종 검수 요청 때 `design/qa-*/`에 남긴다.

debug 갤러리는 실제 `ThemePreviewScreen`과 공통 렌더러를 사용한다. `theme-preview`, `theme-preview-empty`, `theme-preview-loading`, `theme-preview-error`로 상태를 제공하고 오류의 재시도는 준비 상태로 전환한다. 가상 개인 일정은 debug에만 있다. 갤러리/Preview 정의만으로 시각 검수 완료를 주장하지 않는다.

## 2026-09-25 후속 실행 확인

사용자의 별도 승인으로 최신 debug 빌드가 성공했다. 에뮬레이터에서 실제 설정→테마 진입, Indigo/Dark 비교 취소, Emerald/Dark 적용, Clay/시스템 복귀, 일반·기간 요약 위젯 미리보기를 확인했다. 320dp·한국어·글자 1.5배에서는 첫 화면에 견본이 보이지 않는 사용성 문제가 확인됐다. 나머지 조합·복원·접근성·저장 부작용 계측과 단위 테스트/Lint는 여전히 미검증이다. 세부 환경·증거·개선 제안은 [종합 리뷰](PRODUCT_REVIEW_2026-09-25.md)를 따른다.
