# 아이콘 색상 및 스플래시 전환 — 구현 기록

2026-09-21 사용자 요청: 앱 아이콘 배경색을 현재 앱 디자인과 맞추고 스플래시 애니메이션을 인터랙티브하게 수정.

## 반영

- 적응형 아이콘 배경을 보라색 `#4F46E5`에서 A안 Clay 강조색 `#B5482D`로 변경했다. 기존 흰색 벡터 심볼과 적응형 아이콘의 안전 영역은 유지했다. 아이콘은 사용자별 앱 팔레트와 별개인 고정 브랜드 색이다.
- 호환용 일반/원형 WebP 10개와 스토어용 PNG 두 경로를 기존 벡터 심볼로 재생성했다. `generate_brand_icons.py`가 벡터 원본과 아이콘 배경 리소스를 읽는다. 호환 이미지의 외곽 마스크는 일반/원형으로 유지하며, 실제 지원 버전인 API 26 이상 런처에는 기존 적응형 XML을 우선 사용한다. 스토어 파일 수정은 게시나 배포가 아니다.
- 스플래시 배경은 기존 `activity_background`를 참조한다. 밝게 `#F7F7F2`, 어둡게 `#181B19`, 로고는 각각 Clay 강조색 `#B5482D`/`#EE9278`이다. 상태 표시줄·탐색 표시줄 아이콘도 밝기별 bool 리소스로 맞췄다.
- 기존 760ms 선언과 최대 720ms 반동을 360ms 이내의 한 번 정렬하는 로고 동작으로 바꿨다. 외곽 -12→0도, 전체 크기 0.96→1, 중심 0.94→1과 짧은 투명도 전환을 사용한다. 진행률처럼 0부터 채우거나 반복 회전하지 않는다. 링 형태는 기존 브랜드 심볼이며 앱의 시간 표현을 링으로 되돌리는 변경은 아니다.
- 첫 앱 프레임이 준비되면 기존 `Motion.MediumMs` 200ms 동안 로고만 조금 작아지며 `Spacing.s` 8dp 올라가고 배경이 사라진다. 화면 전체 확대는 제거했다. 전환 오버레이를 누르면 바로 제거한다. 로고 애니메이션 완료를 기다리기 위한 고정 지연이나 별도 대기 화면은 추가하지 않았다.
- 시스템 애니메이션이 꺼졌으면 전환 없이 제거한다. 화면을 벗어나거나 Activity가 종료되면 애니메이션을 취소하고 오버레이·리스너를 정리한다. 탭 동작에는 한/영 접근성 이름을 제공한다.
- Android 12 이상은 시스템 AnimatedVectorDrawable, 이전 버전은 정적 시작 로고와 같은 종료 전환을 사용한다. [Android SplashScreen 지침](https://developer.android.com/develop/ui/views/launch/splash-screen)을 따른다. 최초 시스템 시작 화면은 리소스로 결정되므로 앱에서 별도 지정한 테마가 시스템 테마와 다른 경우의 전환은 실기기 확인이 필요하다.

## 검토 및 미검증

- XML 파싱, 애니메이션 대상 이름·리소스 참조, 최대 종료 시각 360ms·반복 없음, 한/영 문구와 diff 공백을 확인했다.
- 재생성한 아이콘과 벡터 기반 밝게/어둡게 정적 비교 이미지를 확인했다. `qa-brand-refresh/icon-before.png`, `icon-after.png`, `splash-static-before.png`, `splash-static-light.png`, `splash-static-dark.png`는 정적 이미지다. Android 실행 화면이나 애니메이션 검수 증거로 사용하지 않는다.
- **빌드·Lint·단위 테스트·APK 설치·실행 검수는 수행하지 않았다.** 사용자의 명시적 최종 검증 요청을 따른다. 현재 설치 앱은 이 변경 전 코드다.
- 최종 검수: Android 8–11/12+/Galaxy 런처의 아이콘·차가운 시작·따뜻한 시작·복귀, 밝게/어둡게와 앱 테마 강제 설정, 애니메이션 배율 0/1/큰 값, 전환 중 탭·뒤로가기·홈 이동·회전, TalkBack·큰 글자·작은 화면. 이전 위젯 변경의 검수 대기도 유지한다.
- 재생성 스크립트는 Pillow와 resvg-py가 필요하며 일반 앱 빌드에는 필요하지 않다. QA 파일은 Git에서 제외한다.
