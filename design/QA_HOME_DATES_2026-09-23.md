# 홈 날짜 일정 노출 — 2026-09-23

사용자가 날짜 단위 기간도 메인과 목록에 표시하는 제안을 승인했다. 기존에는 날짜 일정만 등록해도 홈에 대표가 없고 ‘예정된 시간 구간이 없습니다’라고 표시됐다.

## 반영한 동작

- 대표: 진행 중인 시간 구간과 수동 선택을 우선하고, 없으면 유효한 날짜 일정 중 종료가 가까운 순서/ID 순서로 표시한다.
- 목록: 다음 시간 구간과 날짜 일정을 작은 제목으로 구분하고 **각각 최대 3개** 표시한다. 대표 날짜는 중복하지 않는다. 진행 중인 다른 시간 구간은 기존 대표 선택 메뉴에 있다.
- 날짜: 종료일 당일은 ‘오늘까지’, 이후는 ‘12일 남음’, 지난 일정은 전체 목록에서 ‘3일 지남’. 아직 시작 전이면 시작/종료일과 ‘시작 전’을 함께 표시한다.
- 유효하지 않은 날짜 범위는 전체 일정에서 ‘기간 확인’으로 표시하고 수정 가능하게 유지한다. 종료·정보 부족·유효하지 않은 범위는 홈 대표/날짜 목록에서 제외한다. 전체 일정의 종료 표시/맨 아래/숨김은 기존 설정을 따른다.
- 홈의 ‘일정 추가’와 전체 일정의 추가 아이콘이 같은 메뉴를 사용한다. 시간 범위와 날짜를 모두 선택할 수 있다. 좁은 폭·큰 글자에서는 홈 제목과 버튼이 다음 줄로 흐른다.
- `NextCountdownHero`, `RemainingTimeText`, `TimeRuler`, `TimeLeftItemCard`, `TimeDetailSheet`와 기존 테마/간격을 재사용한다. 날짜 hero도 같은 80% 상세 시트와 위젯 추가 동선을 사용한다.
- 날짜 차이·경과율 계산, 반복 처리, 저장, 알림, 위젯 D-day 표현과 설정 키는 변경하지 않는다. 홈 대표와 목록에 적용되는 표시/선택 규칙만 추가했다.

## 정적 검토 / 미실행 구분

소스의 날짜 후보 조건·대표 중복 제외·종류별 개수 제한·한/영 리소스 대응·줄바꿈 방식을 검토했다. XML 구문·중복 키 확인, 홈 리소스 49개 참조의 한/영 대응, 새 문구 9개의 포맷 인자 일치, 공백 검사를 통과했다. `HomeSelectionTest`에 현재 작업 우선/수동 선택/날짜 전환/반복 시간 다수/동률/당일/잘못된 범위/빈 데이터 조건을 추가했다. **테스트 소스 추가는 실행 통과를 뜻하지 않는다.**

사용자 지시에 따라 이번 변경의 빌드·Lint·단위 테스트·설치·실제 화면 검수는 실행하지 않았다. 밝게/어둡게, 320dp, 글자 배율 1.5/2.0, 한/영 긴 제목과 날짜, 빈 상태, TalkBack, 실제 날짜 경계는 최종 요청 후 확인한다. 설치된 앱이 이번 변경을 포함한다고 가정하지 않는다. 변경 전/후 이미지 역시 아직 수집하지 않았고 최종 검수 시 `design/qa-*/`에 보관한다.

## 실제 화면 검수 경로

debug `DesignGallery`는 별도 모형 대신 실제 `HomeScreen`을 재사용한다.

| screen | 확인할 내용 |
| --- | --- |
| `home`, `overlap` | 진행 중 시간 대표 유지, 수동 선택, 날짜 목록 동시 노출 |
| `idle`, `dates` | 진행 중 시간 없음/날짜만 있을 때 날짜 대표와 목록 중복 제거 |
| `dates-many` | 시간 일정이 많아도 날짜 목록 표시, 각 종류 최대 3개 |
| `dates-today`, `dates-same-day` | 당일 종료/같은 날 기간을 오늘까지로 표시 |
| `dates-future` | 시작 전·미래의 당일 일정: 종료일까지 일수와 시작 전 상태 |
| `dates-expired`, `dates-invalid` | 홈에서 유효한 예정 일정 없음, 전체 일정에서 수정 가능 |
| `date-items`, `date-grid` | 한/영 일수·오늘까지·지남·기간 확인, 종료 일정 맨 아래 |
| `dates-hide-expired` | 홈→전체 일정 진입 시 종료 일정 숨김 |
| `empty`, `long`, `progress-hidden` | 두 종류 추가, 긴 제목, 눈금 숨김 설정 |

갤러리의 날짜는 고정 예시다. 실제 시간 종료→날짜 대표 전환, 자정 당일→만료, 반복 날짜의 다음 회차 반영, 시간대 변경, 데이터 추가/수정/삭제, 회전/복귀와 사용자 선택 유지는 실제 앱 데이터로 별도 검수한다. 검색·정렬·리스트/그리드 설정 보존, 상세 열기/닫기/80% 높이, 날짜 목록 펼침 및 위젯 추가도 함께 확인한다.
