# A안 적용 검수 — 2026-09-18

A안 ‘시간 중심’을 실제 Android 화면에 적용했다. 대표 시간 숫자·얇은 눈금·구분선 목록을 홈, 편집, 설정, RemoteViews 위젯에 공통으로 사용한다. 검수 환경은 Pixel 9 Pro / Android API 37 에뮬레이터다. 갤러리는 실제 화면 구성요소를 사용하며 예시 데이터는 debug 소스에만 있다.

## 변경과 호환성

- 홈: 진행 중인 구간을 우선하고, 없으면 오늘·달·년을 대표 크기로 표시한다. 겹치는 구간은 종료가 가까운 순서로 선택하고 진행 중 다른 구간으로 전환할 수 있다.
- 검색·정렬·격자·날짜 일정은 ‘전체 일정’에서 유지한다. 제목 탭으로 편집하고 목록 상세에서 삭제를 확인한다.
- 입력: 제목과 시작/종료가 먼저 보인다. 반복·알림·색·아이콘·분류는 추가 설정으로 이동했다. 시간 입력은 12/24시간제와 큰 글자에 대응한다.
- 기본 팔레트는 Clay이며 기존에 저장한 5개 팔레트는 유지한다. 배경·글자 위계는 모든 팔레트에서 동일하다.
- 위젯: 기존 제공자 ID·설정 키·크기 종류를 유지하고 숫자·색·남은 눈금을 맞췄다. 저장된 표시 옵션을 유지하며 신규 위젯은 남은 시간 표기가 기본이다. 미리보기 이미지도 실제 RemoteViews에서 갱신했다.
- 저장 모델·DB 스키마·반복 및 알림 스케줄러·출시 버전은 변경하지 않았다. 시간 구간의 시작 경계는 포함하고 종료 경계는 제외한다. 잘못된 기존 구간은 앱을 종료시키지 않고 비활성으로 처리한다.

## 실제 데이터 동선

테스트 전용 에뮬레이터에 debug APK를 설치했다. 개인 기기 데이터는 사용하지 않았다.

- 시간 구간 생성 → 홈의 진행 중 대표 영역 표시 → 제목 편집 → 앱 종료·재시작 후 저장 유지.
- 날짜 일정 생성 → 달력에서 종료일 변경 → D-2 표시 → 격자 전환 → 제목 검색으로 해당 일정만 표시.
- 삭제 대화상자 취소 후 일정 유지, 다시 삭제 확정 후 검색 결과에서 제거.
- Emerald 테마 선택, 올해 기간 선택, 재시작 후 기간 선택과 표시 유지.
- 실제 시간 입력창에서 99시 입력 시 오류 설명과 확인 불가 상태, 취소 시 원래 값 유지.
- 런처에서 소형 위젯 추가 → 내 일정 선택 → 남은 시간 표시 옵션 저장 → 실제 홈 화면에 제목과 남은 분 표시 → 위젯을 눌러 앱으로 이동. 위젯 설정(이전 캡처), 설치된 위젯(이전 캡처).
- 위젯을 설치한 상태에서 debug APK를 덮어쓴 뒤 같은 위젯 ID와 선택한 일정이 유지되는 것을 확인했다. 기존 시각 표기 옵션을 끄고 켜는 경로에서 `0:40:59` 형식과 ‘40 min’ 형식이 미리보기·설치 위젯에 동일하게 적용된다. 기존 시각 표기(이전 캡처).
- 접근성 노드에서 남은 시간·눈금의 시간 범위와 남은 비율·선택 상태를 확인했다.

## 검수에서 보완한 점

- 큰 숫자의 단위 기준선을 맞췄다. 세 자리 또는 복수 단위는 별도 크기 규칙을 적용하고 글자 배율을 유지한다.
- 좁은 화면에서 ‘이번 달’ 단어가 끊어지던 문제와 영어 앱 이름 줄바꿈을 수정했다.
- 큰 글자에서는 입력 필드를 세로로 배치하고 스크롤과 키보드 여백을 제공한다.
- 좁은 화면의 기본 달력 가장자리 잘림을 발견해 큰 글자·좁은 화면에서는 년·월·일 직접 입력으로 전환했다. 날짜 유효성은 윤년을 포함해 검증한다.
- 영어 단수·복수 표시와 상세 설명의 중복 % 기호를 수정했다.
- 위젯 설정의 표시 옵션은 설명과 스위치를 한 터치·접근성 항목으로 묶었다.

## 검증 범위의 한계

모든 Android 버전·제조사 런처·가로 모드·사용자 색상 대비 조합을 검수한 것은 아니다. TalkBack 음성으로 전체 탐색하는 실기기 시험과 실제 알림 도착·배터리 절전 환경 시험은 별도다. 기존 위젯 설치 상태에서 출시 APK를 덮어쓰는 업그레이드 시험은 수행하지 않았다. DB/반복/알림/출시 버전은 유지했으며 스토어 배포는 하지 않았다.
