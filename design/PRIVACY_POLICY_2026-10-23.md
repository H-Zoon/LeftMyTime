# 개인정보 처리방침

시행일: 2026년 10월 23일

dev-idea(이하 “개발자”)는 TimeLeft 이용자의 개인정보와 이용정보를 보호하기 위해 다음과 같이 개인정보 처리방침을 공개합니다.

## 1. 기기에 저장되는 데이터

TimeLeft의 일정·위젯·집중 기능은 계정 가입 없이 이용할 수 있습니다. PointHome의 회원가입과 리워드 서비스 이용 절차는 별개입니다. 일정 제목·날짜·시간, 카테고리, 알림·위젯·테마 설정, 집중 기록, 입력 틀과 이야기 저장 내역은 기기의 앱 전용 저장공간에 보관됩니다. Android 자동 클라우드 백업은 비활성화되어 있으며 기기 간 전송의 적용은 운영체제·제조사 정책에 따라 다를 수 있습니다.

직접 백업을 선택하면 일정·입력 틀·집중 상태를 포함한 파일을 사용자가 고른 저장 위치에 씁니다. 클라우드 파일 서비스를 선택하면 해당 서비스의 정책이 적용됩니다. 복구는 파일을 읽어 미리보기와 확인 후 기기 내 데이터에 적용합니다. 앱 제거로 외부에 저장한 백업 파일까지 삭제되지는 않습니다.

캘린더 가져오기는 읽기 권한 허용 후 기기에 표시된 캘린더와 선택 기간의 회차를 읽고, 고른 회차만 독립 일정으로 복사합니다. 원본 캘린더를 수정하거나 자동 동기화하지 않습니다.

## 2. 자동으로 수집·전송하는 정보

앱 이용 분석과 안정성 개선을 위해 이용 통계, 오류 보고서와 성능 정보를 Google Firebase로 자동 수집·전송합니다. 메시지 전달과 원격 기능 설정을 위한 설치·등록 정보도 Firebase에서 처리합니다. 앱 내에서 수집을 끄는 선택 항목은 제공하지 않습니다. 이 방침이 적용되는 버전으로 업데이트하면 이전 버전의 공유 선택과 관계없이 자동 수집·전송이 활성화됩니다.

- 이용 통계: Firebase Analytics가 앱 인스턴스 식별자, 앱 실행·세션, 앱 버전, 운영체제·기기 모델, 설치 경로 및 대략적인 지역 정보 등을 처리할 수 있습니다. 앱이 추가하는 이벤트는 새 일정 입력 시작·저장 완료, 위젯 설정 완료, 테마 적용·취소, 집중 시작 여부, 리워드 소개 화면의 표시와 선택(알림 받기·받지 않기·닫기) 결과, PointHome 진입 여부와 진입 경로(플로팅 버튼·리워드 알림)입니다. 이벤트에 사용자 입력 문자열, 일정·캘린더 식별자, 정확한 일정 날짜·시간을 추가하지 않습니다. 자동 화면 조회 수집은 끕니다.
- 오류 보고서: Firebase Crashlytics가 충돌·ANR 보고서, 스택 트레이스, 관련 앱 상태, 앱 버전, 운영체제·기기 정보, 발생 시각, Firebase·Crashlytics 설치·세션 식별자를 수집·전송합니다. SDK의 자동 수집·전송을 활성화하며, 앱 종료 등으로 기기에 대기 중인 보고서는 후속 앱 실행에서 전송될 수 있습니다.
- 메시지 전달: Firebase Cloud Messaging이 앱 설치별 메시지 전달을 위해 Firebase 설치 ID(FID)와 등록 정보를 처리합니다. 앱은 일정 제목·내용·정확한 일정 날짜를 메시지 등록 정보에 추가하지 않습니다. 알림 표시 여부는 기기의 앱 알림 권한과 메시지 채널 설정에서 변경할 수 있으며, 알림 표시 차단과 Firebase 등록 정보 처리는 별개입니다.
- 선택형 리워드·혜택 안내: 앱 설정 또는 처음 안내 화면에서 별도로 수신을 선택한 경우 리워드 알림 토픽을 구독하여 안내를 받습니다. 기본값은 꺼짐이며 동의 선택은 기기에 저장합니다. 끄면 토픽 해제를 요청합니다. 해제는 비동기로 처리되므로 이미 발송되었거나 대기 중인 메시지가 도착할 수 있습니다. 리워드 알림은 별도 채널에서 관리하며, 이 선택을 꺼도 일반 메시지용 FCM 설치·등록 정보 처리는 유지됩니다. 동의값을 별도의 Analytics 사용자 속성으로 전송하지 않습니다.
- 성능 정보: Firebase Performance Monitoring이 앱 시작·화면 렌더링·지원되는 네트워크 요청과 홈 데이터 준비·위젯 갱신의 소요 시간을 처리합니다. Firebase 설치·세션 ID, 앱 버전, 기기·운영체제·언어·통신망 정보와 IP에 기반한 국가 정보 등이 포함될 수 있습니다. 네트워크 계측에는 요청 URL(쿼리 매개변수와 본문 제외), 응답 코드·크기·시간이 포함될 수 있습니다. 앱이 추가하는 속성은 고정된 처리 결과뿐이며 일정 제목·식별자·정확한 일정 날짜는 넣지 않습니다.
- 원격 설정: Firebase Remote Config가 Firebase 설치 ID를 사용해 해당 앱 설치에 적용할 기능 설정을 내려줍니다. 현재 위젯 초 표시의 제공 여부를 조절하며, 일정 내용이나 사용자 정의 입력을 원격 설정 요청에 추가하지 않습니다.

Firebase Analytics의 광고 ID 수집과 광고 개인화 설정은 비활성화합니다. 이 설정은 PointHome 및 연동 광고 서비스의 정보 처리에는 적용되지 않습니다. 개발자는 Firebase에 별도의 사용자 ID, 일정 내용, 사용자 정의 Crashlytics 키·로그를 설정하지 않습니다. 오류 스택 등 SDK 진단 정보의 모든 내용이 익명임을 보장하는 것은 아닙니다. 기능 이벤트가 오류 분석의 이동 경로에 포함될 수 있습니다.

데이터는 SDK의 전송 주기와 네트워크 연결 상태에 따라 기기에 임시 저장된 뒤 전송될 수 있으며, 모든 정보가 발생 즉시 전송되는 것은 아닙니다.

### PointHome 리워드·광고 서비스

앱은 주식회사 아바티가 제공하는 PointHome(포인트홈)을 연동하여 리워드·혜택 서비스를 제공합니다. PointHome 및 연동 광고 사업자는 서비스와 광고의 제공·측정·개선, 포인트 적립 및 부정이용 방지 등을 위해 광고식별자(ADID), 기기 모델·운영체제 정보, 서비스 이용기록·접속 로그 및 광고 이용 관련 행태정보 등을 처리할 수 있습니다. PointHome SDK는 앱 실행 시 초기화되며, 회원가입·계좌이체와 같은 이용 절차는 별도로 진행됩니다.

아바티는 PointHome 회원가입 시 휴대전화번호·성별·출생년도, 계좌이체 이용 시 성명·은행계좌 정보 등을 처리한다고 안내합니다. 해당 회원정보·계좌정보는 아바티가 처리하며 개발자는 조회하거나 수신하지 않습니다. 개발자는 일정 제목·내용·캘린더 식별자·정확한 일정 날짜를 PointHome의 회원정보나 광고 사용자 속성으로 지정하여 전달하지 않습니다.

PointHome의 수집 항목·이용 목적·보유 및 파기·제공 관계와 권리 행사 방법은 [아바티 개인정보처리방침](https://www.avatye.com/policy/privacy) 및 해당 서비스의 별도 안내에서 확인할 수 있습니다. 광고식별자 등 처리 정보의 보유·삭제 기준도 해당 서비스의 안내를 따릅니다. 리워드 알림 수신 선택과 PointHome의 회원·광고 정보 처리는 구분됩니다.

## 3. 처리 목적

- 앱 이용 현황과 기능 사용 추세를 통계적으로 파악
- 충돌, ANR 및 오류 원인을 분석하고 앱 안정성을 개선
- 운영체제·기기·앱 버전별 문제를 진단
- 앱 설치별 메시지를 전달하고 알림을 표시
- 앱·위젯 처리 지연을 파악하고 기능의 제공 범위를 원격으로 조절

개발자는 Firebase로 수집된 정보를 앱 이용 분석, 안정성·성능 개선, 메시지 전달과 기능 설정에 사용하며, 이용자가 작성한 일정 내용의 분석에는 사용하지 않습니다. PointHome 및 연동 광고 사업자의 처리 목적은 위 PointHome 안내와 해당 사업자의 방침에 따릅니다.

## 4. 처리 위탁 및 국외 처리

개발자는 제2조의 Firebase 관련 기능을 위해 Google LLC 및 그 계열사·재위탁업체가 운영하는 Firebase에 정보 처리를 위탁합니다.

- 수탁자: Google LLC 및 Firebase 서비스 재위탁업체
- 처리 장소: 미국을 포함하여 Google 또는 그 대리인이 시설을 운영하는 국가의 글로벌 인프라
- 이전 시점과 방법: 앱 이용 중 또는 후속 앱 실행에서 SDK의 전송 주기와 네트워크 연결 상태에 따라 암호화된 HTTPS 통신으로 자동 전송
- 목적: 이용 통계, 충돌 보고와 안정성·성능 분석, 메시지 전달, 원격 기능 설정

Firebase는 서비스 제공을 위한 재위탁업체 또는 개발자의 별도 지시에 따른 연동을 제외하고 수집 정보를 제3자에게 이전하지 않는다고 안내합니다. 개발자는 현재 Firebase 데이터를 광고 서비스나 별도의 비 Firebase 서비스에 연결하도록 앱을 구현하지 않았습니다.

## 5. 보유 및 파기

- Firebase Analytics: 사용자·이벤트 수준 데이터는 Google Analytics 속성 설정에 따른 기간 동안 보관되며 표준 속성에서 최대 14개월입니다. 집계된 표준 보고서는 Google의 별도 보관 정책이 적용될 수 있습니다.
- Firebase Crashlytics: 충돌 스택과 관련 설치 식별자는 Firebase 정책에 따라 90일간 보관된 후 라이브 및 백업 시스템에서 삭제 절차가 시작됩니다.
- Firebase Performance Monitoring: IP 관련 이벤트는 30일, 설치 관련·비식별 성능 정보는 60일 보관 후 라이브 및 백업 시스템에서 삭제 절차가 시작됩니다.
- Firebase Remote Config: 설치 ID는 삭제 API가 호출될 때까지 보관하며, 호출 후 라이브 및 백업 시스템에서 제거되기까지 최대 180일이 걸릴 수 있습니다.
- 기기 내 데이터: 앱의 데이터 삭제 또는 앱 제거 시 기기에서 삭제됩니다.
- PointHome 관련 정보: 아바티의 개인정보처리방침과 서비스별 안내에 따른 보유·파기 기준이 적용됩니다. 아바티는 회원 탈퇴 또는 처리 목적 달성 시 파기를 원칙으로 하며 법령 등에 따른 보존이 필요한 경우 해당 기간 보관한다고 안내합니다.

## 6. 이용자의 권리와 행사 방법

이용자는 개인정보의 열람, 정정, 삭제 또는 처리정지를 요청할 수 있습니다. 아래 이메일로 요청하면 관련 법령과 서비스의 기술적 범위 안에서 처리합니다. TimeLeft 기본 기능에 계정이나 직접 식별정보가 없어 특정 Firebase 기록을 개인과 연결할 수 없는 경우에는 개별 기록의 식별·삭제가 제한될 수 있습니다.

기기에 저장된 일정과 설정은 Android 시스템의 앱 정보에서 데이터를 삭제하거나 앱을 제거하여 직접 삭제할 수 있습니다. 직접 저장한 백업 파일은 해당 파일 서비스에서 별도로 삭제해야 합니다. 기기 내 데이터를 삭제하거나 앱을 제거해도 이미 전송된 Firebase 데이터가 즉시 삭제되는 것은 아닙니다.

PointHome이 처리하는 회원·리워드·출금정보에 대한 열람·삭제·탈퇴 등은 해당 서비스의 문의 절차 또는 아바티의 개인정보 문의처 [privacy@avatye.com](mailto:privacy@avatye.com)으로 요청할 수 있습니다. TimeLeft의 앱 데이터 삭제·앱 제거 또는 리워드 알림 해제가 PointHome 탈퇴나 외부 사업자가 보유한 정보의 자동 삭제를 의미하지는 않습니다.
