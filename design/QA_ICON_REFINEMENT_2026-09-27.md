# 기존 아이콘 형태 유지 · 세부 정돈

사용자 요청: 기존 아이콘을 계속 사용하며 현재 모양에서 크게 벗어나지 않는 방향으로 개선.

## 반영 범위

- 두 겹의 열린 원, 왼쪽 세 가로선, 중앙 V 표시, Clay `#B5482D` 배경과 흰색 심볼을 유지했다. 앞선 눈금/단일 시계 시안은 채택하지 않았다.
- 512 좌표계에서 바깥 원·안쪽 원의 선 굵기 26/25를 24로 맞췄다. 바깥 원을 정확한 중심(256, 256)에 맞추고 안쪽 반지름을 89에서 92로 소폭 조정했다. 두 원 사이 공간은 약 34로 유지한다.
- 왼쪽 가로선 시작을 x94로 맞췄다. 가로선의 세로 범위는 94–118, 150–174, 206–230으로 두께24·사이 간격32를 공유한다. 짧은 두 선의 오른쪽 끝은 바깥 원의 안쪽 반지름138을 따라 잘린 형태다.
- 중앙 V는 좌우 대칭으로 맞추고 조금 위로 이동했다. 선 굵기를18에서20으로 보강했다. 스플래시 중앙 표시의 크기 변화 기준도 새 도형 중심 y260에 맞췄다.
- `ic_launcher_playstore_foreground_vector.xml`, 적응형 `ic_launcher_foreground.xml`, `splash_icon_foreground.xml`에 같은 다섯 도형을 반영했다. 적응형0.63·스플래시0.6 안전 영역, 모션 대상 이름·시간·회전 범위와 테마 색상은 유지한다.
- 기존 `generate_brand_icons.py`로 스토어 PNG2개와 일반/원형 WebP10개를 다시 만들었다. 남아 있던 밀도별 전경 PNG5개도 적응형 XML과 같은 크기·배율로 생성하도록 보완했다. 이 PNG는 현재 적응형 XML에서 직접 참조하지 않는 호환 리소스다.
- 공통 테마의 Clay 색상, 기존 벡터/스플래시 리소스 구조와 생성 스크립트를 재사용한다. 새로운 효과·문구·설정·데이터 변경은 없다. 이미지 생성은 앱 빌드 과정과 별개다.

## 정적 확인

- 세 벡터의 도형·선 설정 일치, XML 파싱, 기존 애니메이션의 대상 이름 연결과 안전 영역 설정을 확인했다.
- 스토어512px, 호환48/72/96/144/192px, 전경108/162/216/324/432px 파일 규격과 투명 영역을 확인했다.
- 실제 벡터를 변환한 전후 이미지의 확대/64/48/32px 사각·원형 마스크와 밝게/어둡게 로고 색상에서 선 간격·대칭·잘림을 육안 확인했다. 작은 마스크 이미지는 비교용이며 런처의 실제 마스크·안전 영역 처리를 재현한 기기 캡처가 아니다.

원본 비교 XML/PNG와 위 이미지는 Git에서 제외되는 `design/qa-icon-refinement/`에 있다. 생성된 제품용 이미지는 리소스/스토어 경로에 남는다.

## 미검증

- **이번 변경 후 빌드·Lint·단위 테스트·APK 설치·기기 화면 검수는 수행하지 않았다.** 사용자 명시적 요청 시 진행한다. 현재 설치 앱에는 수정 전 심볼이 남아 있다.
- Android 런처별 실제 아이콘 마스크·캐시 갱신, 앱 업데이트 전후, Android8–11/12+ 시작 화면과 모션 연결은 최종 실행 검수 대상이다. 정적 이미지를 실행 검수로 간주하지 않는다.
- 큰 글자·긴 제목·빈 일정은 이번 심볼 도형과 무관해 새로 검수하지 않았다. 다른 UI의 미검증 범위는 기존 기록을 유지한다.
- 커밋·스토어 게시·배포는 진행하지 않았다.
