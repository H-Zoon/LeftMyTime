> 홈 동선 후속 수정: 하단 ‘전체 일정 N개 보기’를 제거하고 상단 진입만 유지했다. 아래 이미지는 해당 제거 전 기록이며 최신 화면은 아직 빌드·캡처하지 않았다.

> 안내 문구 후속 수정: ‘각 기간을 누르면 자세히 볼 수 있어요’로 변경하고 영어 문구도 설명형으로 맞췄다. 기존 안내 구성요소를 사용하며 새 문구의 실제 화면 확인과 최종 빌드·Lint·단위 테스트는 보류 중이다.

> 후속 수정: 사용자 요청에 따라 기간별 화살표를 코드에서 제거했다. 안내문과 항목 전체의 상세 진입은 유지한다. 빌드·Lint·단위 테스트와 새 화면 캡처는 실행하지 않았다. 아래 이미지와 검수 내용은 화살표 제거 전 설치 앱의 기록이며, 최신 코드의 시각 검수 완료를 뜻하지 않는다.

# 기간 상세 진입 안내 보완 — 2026-09-18

사용자가 공통 ‘자세히’ 버튼을 없애고 ‘눌러서 자세히 보기’ 안내를 두도록 선택했다. 이 결정은 이전의 마지막 기간 기억·공통 상세 버튼을 대체한다.

- 정적인 안내문과 각 기간의 오른쪽 화살표로 상세 진입을 표시한다. 항목의 이름·숫자를 포함한 전체 영역이 하나의 버튼이며 최소 48dp를 유지한다.
- 누른 기간을 기존 하단 상세로 연다. `RemainingTimeText`, `TimeRuler`, 기존 테마·간격을 재사용한다.
- 마지막 기간의 설정 읽기·저장, 홈 콜백, debug 갤러리의 초기 기간 선택을 제거했다. 기존 `home_header_index` 값은 삭제하지 않고 더 이상 사용하지 않는다. 열려 있는 상세의 화면 회전용 임시 상태는 유지한다.
- 작은 화면·큰 글자에서는 안내문이 줄바꿈되고 기간별 화살표가 행 끝에 놓인다.

## 화면 확인

검증 보류 지시 전에 만든 APK가 설치된 테스트 에뮬레이터에서 확인했다. 이 화면을 확인한 당시에는 설치 이후 앱 소스 차이가 미사용 import 제거뿐이었다. 이후의 화살표 제거·안내 문구·전체 일정 진입 및 목록 개선은 아래 검수 결과에 포함되지 않는다.

- 오늘·이번 달·올해를 각각 눌러 해당 기간의 상세와 범위가 열리고 닫히는 것을 확인했다. [오늘](qa-period-hint/detail-today.png), [이번 달](qa-period-hint/detail-month.png), [올해](qa-period-hint/detail-year.png).
- 320dp, 한글 1.5배 긴 제목·빈 일정, 영어 2배 23시간 59분·세 자리 일수·월 상세를 확인했다. [긴 제목](qa-period-hint/long-clay-dark-320-font1.5.png), [빈 일정](qa-period-hint/empty-clay-light-320-font1.5.png), [영어 2배](qa-period-hint/period-long-clay-light-320-font2-en.png).
- 실제 앱에서 오늘과 올해를 열고 닫은 후 재시작했을 때 상세가 자동으로 열리지 않음을 확인했다. 조작 전후 설정 파일 내용도 동일했다. [재시작 화면](qa-period-hint/real-restart.png).
- 안내문 자체는 클릭 동작이 없고, 실제 기간 항목은 접근성 노드에서 버튼으로 노출된다. 장식 화살표는 별도 접근성 항목으로 추가하지 않는다.

## 최종 검증 운영

사용자 지시에 따라 이후 빌드·Lint·단위 테스트는 모든 수정사항 반영 후 **명시적으로 요청한 때만** 실행한다. 해당 지시 이후 추가 실행하지 않았다. 기존 검사의 통과를 향후 수정사항에 대한 최종 승인으로 확대하지 않는다.

TalkBack 실제 음성·접근성 초점 복귀, 가로 화면, 글자 2배 초과는 이번에 확인하지 않았다. 기존 팔레트 전체 조합은 앞선 요약 검수 기록을 참고하며 이번에는 기본 밝게/어둡게를 확인했다.
