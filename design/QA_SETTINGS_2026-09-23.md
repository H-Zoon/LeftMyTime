# 설정 선택 방식 정리 — 2026-09-23

사용자가 라디오 목록 대신 현재값 중심의 드롭다운을 사용하는 제안을 승인했다. 설정의 전체 선택지가 펼쳐져 스크롤이 길고 현재 상태를 훑기 어려운 문제를 다룬다.

후속 변경: 같은 날 테마 미리보기를 승인받아 화면 모드 드롭다운과 색상 견본을 별도 미리보기 화면으로 옮겼다. 화면 섹션에는 현재 테마와 오늘의 작은 견본을 표시하며, 모드·색상은 ‘적용’ 시 함께 저장한다. 정렬·만료·기본 알림 드롭다운과 진행률 스위치는 유지한다. 아래는 최초 드롭다운 변경 기록이며 테마의 최신 범위는 [테마 미리보기 기록](QA_THEME_PREVIEW_2026-09-23.md)을 따른다.

## 반영 범위

- 화면 모드 3개, 기본 정렬 4개, 만료 항목 처리 3개, 날짜 기본 알림 5개, 시간 기본 알림 5개를 `SettingsDropdownRow`로 통일했다. 기존 옵션/값/저장 콜백을 유지한다.
- 항목명 왼쪽·현재값 오른쪽의 baseline을 맞춘다. 작은 화면(행 가용 폭 300dp 미만)과 큰 글자(1.2배 초과)는 이름/현재값을 세로로 표시한다. 메뉴는 행과 같은 폭이며 선택 문구가 길면 줄바꿈한다.
- 행 전체를 누르면 메뉴가 열리고 현재 선택에 체크와 `selected` 접근성 상태를 제공한다. 열림/닫힘과 선택 변경 동작도 이름을 갖는다. 터치 높이는 최소 48dp다.
- 항목 선택 시 먼저 닫고 기존 저장 콜백을 실행한다. 현재값 재선택·바깥 탭·뒤로 닫기는 값을 쓰지 않는다. 알 수 없는 값은 ‘선택’으로 표시하고 자동으로 덮어쓰지 않는다.
- 기본 정렬을 ‘홈 동작’에 한 행으로 묶었다. 진행률 표시는 하나의 스위치로 바꾸고 행/스위치를 같은 동작으로 취급한다. 색상 견본, 권한 설정 이동, 날짜 알림 시각, 개인정보 처리방침과 버전은 유지했다.
- 기존 `bar_only` 값은 화면을 보는 것만으로 변경하지 않고 켜짐으로 표시한다. 사용자가 스위치를 끄면 `hidden`, 다시 켜면 기존 표시 선택과 같은 `full`을 저장한다. 저장 키나 옵션 마이그레이션은 추가하지 않았다.
- `TimeLeftTopAppBar`, `TimeLeftSection`, `TimeLeftTheme`, `Spacing`, `LayoutTokens`와 Material 드롭다운/스위치를 사용한다. 추가 카드, 별도 팔레트, 글꼴 크기, 그림자를 정의하지 않았다.

## 확인 범위

이번 변경은 UI와 접근성 표현 범위다. 새 단위 테스트는 추가하지 않았다. 소스와 기존 콜백 대응, 한/영 XML 구문·중복 키·설정 리소스 33개 참조, 공백 검사를 정적으로 확인했다. **빌드·Lint·단위 테스트·새 APK 설치·실제 화면 검수는 실행하지 않았고 사용자 명시적 요청까지 보류한다.** 설치 앱이 이번 변경을 포함한다고 가정하지 않는다.

변경 전후 캡처는 아직 없으며 최종 요청 시 `design/qa-*/`에 남긴다. Preview/debug 사례 추가는 시각 검수 통과를 의미하지 않는다.

## 최종 검수 조건

- 밝게/어둡게·6개 팔레트·320dp와 일반 폭·글자 1.0/1.5/2.0·한/영에서 닫힌 행/열린 메뉴/긴 항목명/설명 줄바꿈과 화면 밖 잘림 확인.
- 드롭다운 5개에서 현재값과 체크 일치, 전체 선택지 접근, 선택/바깥 탭/뒤로 닫기, 화면 아래 메뉴 위치와 세로 스크롤, 키보드·TalkBack 초점과 선택 상태 확인.
- 화면 모드/색상 변경 후 메뉴 닫힘·현재값 갱신, 회전/재진입 후 저장값 표시. 기본 정렬·만료 설정이 홈/전체 일정에 반영되는지 확인.
- 스위치 행·스위치 각각 탭 시 한 번만 변경, 켜짐/꺼짐 접근성, 기존 `bar_only` 무조작 보존, 기존 홈/상세/위젯 갱신 경로 확인.
- 알림 없음/모든 기본 알림 값, 권한 허용/거부 안내, 날짜 알림 시각 이동 확인. 새 일정의 기본값 반영과 기존 일정 알림 불변을 확인한다. 선택 취소로 알림/설정이 변경되지 않아야 한다.
- 설정은 사용자 일정 데이터가 비어 있어도 동일하다. 빈 계정에서도 옵션과 현재값이 정상 표시되고 사용자 일정/DB가 생성되지 않는지 확인.

`DesignGallery`의 `settings`는 기본값, `settings-selected`는 비기본 정렬/알림·진행률 숨김·알림 권한 꺼짐, `settings-legacy`는 기존 `bar_only` 값이다. 실제 `SettingsScreen`을 쓰며 드롭다운·스위치·색상·테마 변경은 갤러리 로컬 상태에만 반영한다. 날짜 알림 시각/시스템 설정/개인정보 이동·실제 저장·알림 갱신은 일반 앱에서 확인한다.
