# 다른 PC에서 이어서 작업하기

정리일: 2026-09-18. 현재 기준은 [디자인 시스템 v2](DESIGN_SYSTEM.md)의 A안 ‘시간 중심’이다.

## 코드에 반영된 상태

- 홈: 상단 오늘·이번 달·올해 요약, 각 기간 직접 상세 진입, 안내 문구, 반복 화살표 제거, 전체 일정 진입 통합.
- 전체 일정: 보기/검색/정렬 간격, 공통 밑줄 입력, 상세 펼침·접힘 애니메이션.
- 위젯: 크기와 표시 항목 분리, 독립 기간 요약, 기존 설치 표시 보존, 저장된 선택 복원, 실제 렌더러 공유 미리보기.
- 위젯 추가 목록: 오늘·이번 달·올해·기간 요약·내 일정. 기존 네 provider 식별자를 유지하고 일정 provider 하나를 추가했다.
- 설정: 선택 요약, 별도 내용 선택/일정 검색, 시간·날짜 보조 정보, 필요한 표시 형식만 노출, 크기 부족·오류·삭제 안내.
- 사용자가 보고한 `AppWidgetConfigure.kt`의 `maxWidth` 수신 범위 오류는 `BoxWithConstraints` 안에서 지역 변수로 받아 중첩 `Column`에서 사용하도록 수정했다. 수정 후 컴파일 확인은 아직 하지 않았다.

## 검증 상태와 다음 작업

**사용자의 명시적 요청 전에는 빌드·Lint·단위 테스트를 실행하지 않는다.** 이 규칙은 다른 PC에서도 유지한다.

최근 위젯 변경은 XML 구문·문구·리소스 참조·소스·문서 링크를 검토했다. 이전 커밋의 테스트 통과나 화면 검수를 최근 코드의 검증으로 간주하면 안 된다. 전체 일정의 후속 간격·입력·애니메이션 변경과 새 위젯 화면은 최종 검증 대기다.

요청을 받은 뒤 다음을 확인한다.

1. 기본 코드 검증: `./gradlew testDebugUnitTest assembleDebug lintDebug` (Windows는 `gradlew.bat`). 기존 경고와 새 문제를 구분한다.
2. 새 APK의 실제 화면: 밝게/어둡게·320dp·큰 글자·긴 한/영 제목·빈 상태·검색·선택·상세 애니메이션.
3. 기존 네 위젯이 설치된 상태에서 업데이트: ID·선택 일정·표시 모드·크기 유지, 재설정 저장/취소.
4. 다섯 신규 진입의 기본 내용과 크기, 새 일정 provider 갱신, 기간 요약 크기 부족과 확대 후 복구, 설정 미리보기와 설치 결과 일치.
5. 일정 조회 오류/재시도·선택 일정 삭제·날짜 경계·반복, 접근성 및 실제 런처별 동작.

상세 범위:

- [전체 일정 변경 기록](ALL_SCHEDULES_REFINEMENT.md)
- [위젯 내용 분리·호환 조건](QA_WIDGET_CONTENT_2026-09-18.md)

실제 화면을 재사용하는 debug 갤러리와 테스트 소스는 보존했다. 새 QA 캡처는 Git에서 제외하는 `design/qa-*/`에 저장한다. 캡처나 Preview 추가만으로 시각 검수를 완료 처리하지 않는다.

## 새 환경 준비

- Android Studio, Android SDK 36, JDK 17 toolchain을 준비한다. Gradle Wrapper와 프로젝트 설정은 저장소에 포함되어 있다.
- SDK 경로·Gradle의 로컬 Java 경로·에뮬레이터 선택은 새 PC에서 설정한다. 기존 PC의 절대 경로나 생성 캐시를 옮길 필요는 없다.
- `local.properties`, 서명 키, `keystore.properties`는 Git에 포함하지 않는다. 출시 서명이 필요한 작업에서만 별도로 준비한다.
- 앱에 필요한 위젯 XML/PNG와 PNG 생성 스크립트, 스토어 등록용 `store-assets/`의 아이콘·배너는 보존했다. 위젯 PNG 재생성은 일반 빌드에 필요하지 않으며 Pillow와 한글 지원 산세리프 글꼴이 있을 때 수행한다.

## 이번 정리 범위

QA PNG·화면 XML·비교 이미지·결과 JSON, PC 경로가 고정된 촬영/합성 스크립트, Python/Kotlin/Gradle 캐시·앱 빌드 출력, IDE 기기 선택·미리보기 확대 기록, 더 이상 참조하지 않는 이전 위젯 PNG를 제거했다. 디자인 결정·검수 범위·미검증 조건은 텍스트로 남겼다.

이전에 커밋된 QA 파일은 `8986d02`의 `design/qa`, `design/qa-v2`, `design/qa-flow`, `design/qa-period-hint`에서 확인할 수 있다. Git 이력은 재작성하지 않았다. 폐기한 미커밋 `qa-affordance` 캡처는 최종 기준이나 검수 증거로 사용하지 않는다.

앱에서 바로 위젯을 추가하는 pin 기능, 자동 선택의 종료 일정 정책, 갱신 주기 개선은 별도 후속 작업이다. DB 스키마·기존 일정·앱 출시 버전은 이번 개편으로 변경하지 않았다.
