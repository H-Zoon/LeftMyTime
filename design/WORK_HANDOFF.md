# 다른 PC에서 이어서 작업하기

2026-10-06 실행 검증 후 지원 확대: ‘그럼 시험해 봐’ 요청으로 **문서6/8 실제 런처의 초 숫자·눈금·시작/종료·프로세스 종료·화면 복귀·오늘, 문서6 자정 순환**을 확인했다. 제품 지원을 `API >=35`이면서 문서 `6`, `8`, 기존 `>=9`로 확대했다. 기본값 꺼짐·실험 기능 유지. 단위113개·debug/계측 빌드·Lint 오류0, 최종6/8 위젯 계측 각각6통과/2조건제외. Android15/문서1은 정적 표시 유지. **문서8 확대 안내 접근성 1×1px 결함과 실기기 전력/런처는 미해결·미검증.** [최신 실행 기록](QA_WIDGET_SECONDS_COMPATIBILITY_2026-10-06.md)을 따른다. 아래 미빌드/문서9 이상 유지 설명은 이전 이력이며 사용자 휴대폰에는 아직 설치하지 않았다.

2026-10-05 초 표시 하위 기기 후속 구현: ‘진행’ 요청으로 **문서 6 전용 V6 생성기, 문서 8용 기존 V7 생성기, 제품/검증 지원 판정 분리**를 반영했다. debug probe의 `candidate` 모드에서 실제 제품 렌더러로 오늘/시간 일정·시작 전/종료·크기/글자/테마를 시험할 수 있고 호스트 버전과 선택 형식을 표시한다. 헤더·최초 시스템 그리기·지원 범위 회귀 테스트 소스도 확장했다. **일반 사용자 초 옵션은 기존 문서 9 이상 유지, 빌드·Lint·단위/계측·설치·시각 검수 미실행.** 하위 호스트의 지속 갱신/접근성/전력 확인 후에만 지원을 승격한다. 코드 범위·실행 명령·남은 검증은 [최신 호환성 기록](WIDGET_SECONDS_COMPATIBILITY_2026-10-05.md)을 따른다. 아래 ‘조사 문서만 변경’은 구현 전 이력이다.

2026-10-05 초 표시 하위 기기 재조사: [최신 호환성 조사](WIDGET_SECONDS_COMPATIBILITY_2026-10-05.md). 공개 Android 16 / QPR1 문서 6에도 정수 epoch·초 틱·핵심 연산/레이아웃/접근성 명령이 있음을 확인했다. 문서 8의 기존 V7 경로 외에 **문서 6 전용 V6 생성기/헤더**도 검증 후보로 추가한다. `>=9`를 단순히 `>=6`으로 바꾸면 구형 헤더와 맞지 않는다. Android 15 이하 Chronometer의 종료 후 음수·눈금/문구 비동기 문제는 남는다. **이번에는 조사 문서만 변경, 앱 코드·지원 조건·기본값 유지, 빌드·테스트·설치 미실행, 연결 기기 0대.** 기존 제품 probe/플랫폼 테스트의 출시 gate를 시험 gate와 분리한 실제 문서 6/8 검증이 다음 구현 단위다.

2026-10-05 위젯 갱신 복구 후속: 사용자 확인으로 증상은 **9월 29일 커밋 미설치 상태의 기존 앱**에서 발생했다. [최신 분석·수정·검증 대기](WIDGET_REFRESH_RECOVERY_2026-10-05.md). 기존 렌더러에 WorkManager 고유 15분 주기 복구(게시 전 등록·KEEP·부분 실패 재시도·마지막 위젯 삭제 시 취소), 대기 알람 보존/10분 비정확 창, 실패 후 재예약, 과거 예약이 가까운 미래 경계를 가리던 오류, 초 미지원 Next 경계·업데이트 방송 복구와 로컬 수신/제출 로그를 반영했다. 회귀 테스트 소스를 추가했다. **빌드·Lint·단위/계측 테스트·설치 미실행, 연결 기기 0대, 실제 해결 여부·전력 영향 미검증.** 15분 정확 갱신이나 홈 복귀 즉시 갱신 보장이 아니다. 새 WorkManager 의존성의 전체 빌드/manifest 확인과 One UI 장시간 관찰이 남아 있다.

2026-09-29 위젯 3시간 미갱신 보완: [조사·변경 기록](WIDGET_STALE_INVESTIGATION_2026-09-29.md). 사용자 확인은 Android15·하루 요약·수동 갱신 성공이다. 연결 Samsung/6.5(22)의 등록·알람·방송을 읽기 전용 확인하고, 정적 시간 위젯의 자체 15분 갱신 요청(비기상·비정확), 지난 예약 보존, 위젯별 오류 격리, 상세 진입 시 갱신을 코드에 반영했다. 기존 예약/Receiver/렌더러를 재사용한다. **15분 실제 갱신 보장 아님, 원래 자동 전달 실패 원인은 미확정. 빌드·Lint·테스트·설치 미실행이며 휴대폰에는 미반영.** 시간 계획 회귀 테스트 소스를 추가했고 One UI 3시간 이상 관찰과 API37 회귀가 남아 있다.

2026-09-28 위젯 하위 버전 가능성 조사: [호환성 조사](WIDGET_SECONDS_COMPATIBILITY_2026-09-28.md)에 Android 16 QPR2/문서 버전 8의 정수 시계·초 갱신 소스와 현재 WIDGETS_V7 생성 프로파일을 대조했다. 버전 8은 확대 검증 후보이며 지원 확정은 아니다. Android 15 초기 소스에는 현 렌더러의 필수 명령이 빠져 있다. **앱 코드·지원 조건은 유지, 빌드·Lint·테스트·실행 검수는 하지 않았다.** 버전 8의 실제 제품 문서/런처 검증이 다음 단계다.

2026-09-28 서명 빌드 후속: 사용자 요청으로 빌드 전에 홈·전체 일정의 본문 행동/검색 입력 왼쪽 시작선을 맞추고 아이콘 심볼을 512 기준 우8·하6 이동했다. 공통 `TimeLeftUnderlineTextField`·새 `TimeLeftInlineButton`·기존 테마/간격과 브랜드 생성기를 사용한다. **6.5(22) 서명 APK/AAB와 debug 빌드, release lintVital, 서명·16KB 정렬 검증을 완료**했다. API37 debug 갤러리에서 320/360dp·한/영·밝게/어둡게·1.5배 글자·긴 제목/빈 상태·검색 입력을 확인했다. 아래 개인정보 변경의 ‘미빌드’는 당시 상태이며, 해당 변경도 이번 산출물에 포함한다. 별도 전체 Lint·단위/계측 테스트·실기기/release 실설치·Firebase 서버 수신은 미검증이다. 정확한 해시·전후 화면·남은 범위는 **[6.5 정렬·서명 기록](QA_ALIGNMENT_RELEASE_2026-09-28.md)**을 따른다. Console 업로드·공개 정책·커밋은 변경하지 않았다.

2026-09-28 개인정보 수집 방식 변경: 사용자 요청으로 설정의 이용 통계·오류 보고 선택 항목을 제거하고 **Firebase Analytics·Crashlytics 자동 수집·전송을 활성화**했다. DB·일정·알림·위젯 로직·출시 버전은 변경하지 않았다.

- UI: 실제 `SettingsScreen`과 갤러리에서 스위치를 제거하고 기존 `SettingsSection`·`NavigationRow`·테마·간격을 재사용한다. 한국어/영어 자동 전송 안내와 앱에 포함되는 [`docs/privacy.html`](../docs/privacy.html)을 갱신했다.

2026-09-27 스토어 준비 후속: Console의 운영 버전6.3(20)을 확인해 **6.4(21)** 서명 APK/AAB를 빌드하고 AAB·출시 노트를 업로드, 릴리즈 초안을 저장했다. 최신 배너·아이콘·실제 구성요소를 촬영한 스크린샷6장과 한글 소개 문구를 스토어 초안으로 저장했다. 광고 ID 미사용·선택형 Firebase 수집에 맞춘 데이터 보안 선언을 저장했으며 **Google 검토 제출·앱 출시는 하지 않았다**.
