## 코드에 반영된 상태

- 홈: 상단 오늘·이번 달·올해 요약, 각 기간 직접 상세 진입, 안내 문구, 반복 화살표 제거, 전체 일정 진입 통합.
- 전체 일정: 보기/검색/정렬 간격, 공통 밑줄 입력, 상세 펼침·접힘 애니메이션.
- 위젯: 크기와 표시 항목 분리, 독립 기간 요약, 기존 설치 표시 보존, 저장된 선택 복원, 실제 렌더러 공유 미리보기.
- 위젯 추가 목록: 오늘·이번 달·올해·기간 요약·내 일정. 기존 네 provider 식별자를 유지하고 일정 provider 하나를 추가했다.
- 설정: 선택 요약, 별도 내용 선택/일정 검색, 시간·날짜 보조 정보, 필요한 표시 형식만 노출, 크기 부족·오류·삭제 안내.
- 사용자가 보고한 `AppWidgetConfigure.kt`의 `maxWidth` 수신 범위 오류는 `BoxWithConstraints` 안에서 지역 변수로 받아 중첩 `Column`에서 사용하도록 수정했다. 2026-09-21 최종 검증에서 컴파일을 확인했다.

## 검증 상태와 다음 작업

2026-09-21 최신 크기 수정: **일반 4×2·기간 요약 4×1**로 기본 배치를 변경했다. 공간 하한은 단일 250×180dp·요약 250×64dp다. 요약의 공통 제목 제거·문자 폭에 따른 열 배분·8dp 세로 여백, 작은 단일 위젯의 8dp 세로 여백, 소스별 안내 및 미리보기 크기도 함께 수정했다. **이 후속 변경에는 이전 빌드·46개 테스트 통과 결과를 적용하지 않는다. 빌드·Lint·단위 테스트·새 APK 화면 확인은 아직 수행하지 않았다.** 기존 설치 앱은 이 변경 전 코드다.

**사용자의 명시적 요청 전에는 빌드·Lint·단위 테스트를 실행하지 않는다.** 이 규칙은 다른 PC에서도 유지한다.

## 새 환경 준비

- Android Studio, Android SDK 36, JDK 17 toolchain을 준비한다. Gradle Wrapper와 프로젝트 설정은 저장소에 포함되어 있다.
- SDK 경로·Gradle의 로컬 Java 경로·에뮬레이터 선택은 새 PC에서 설정한다. 기존 PC의 절대 경로나 생성 캐시를 옮길 필요는 없다.
- `local.properties`, 서명 키, `keystore.properties`는 Git에 포함하지 않는다. 출시 서명이 필요한 작업에서만 별도로 준비한다.
- 앱에 필요한 위젯 XML/PNG와 PNG 생성 스크립트, 스토어 등록용 `store-assets/`의 아이콘·배너는 보존했다. 위젯 PNG 재생성은 일반 빌드에 필요하지 않으며 Pillow와 한글 지원 산세리프 글꼴이 있을 때 수행한다.
