# 다른 PC에서 이어서 작업하기

정리일: 2026-09-18. 후속 업데이트: 2026-09-21. 현재 기준은 [디자인 시스템 v2](DESIGN_SYSTEM.md)의 A안 ‘시간 중심’이다.

## 코드에 반영된 상태

- 홈: 상단 오늘·이번 달·올해 요약, 각 기간 직접 상세 진입, 안내 문구, 반복 화살표 제거, 전체 일정 진입 통합.
- 전체 일정: 보기/검색/정렬 간격, 공통 밑줄 입력, 상세 펼침·접힘 애니메이션.
- 위젯: 크기와 표시 항목 분리, 독립 기간 요약, 기존 설치 표시 보존, 저장된 선택 복원, 실제 렌더러 공유 미리보기.
- 위젯 추가 목록: 오늘·이번 달·올해·기간 요약·내 일정. 기존 네 provider 식별자를 유지하고 일정 provider 하나를 추가했다.
- 설정: 선택 요약, 별도 내용 선택/일정 검색, 시간·날짜 보조 정보, 필요한 표시 형식만 노출, 크기 부족·오류·삭제 안내.
- 사용자가 보고한 `AppWidgetConfigure.kt`의 `maxWidth` 수신 범위 오류는 `BoxWithConstraints` 안에서 지역 변수로 받아 중첩 `Column`에서 사용하도록 수정했다. 2026-09-21 최종 검증에서 컴파일을 확인했다.

## 검증 상태와 다음 작업

2026-09-21 후속 승인: [위젯 개편](QA_WIDGET_REDESIGN_2026-09-21.md)을 코드와 디자인 기준에 반영했다. 단일 시간/기간 요약의 숫자·단위·눈금, 최초 개편 당시 최소 단일 250×200dp·요약 250×240dp·기본 4×3칸, 실제 크기 대응, 추가 목록 미리보기, 항목별 상세 진입, 눈금 숨김 설정·상태 처리·시간 변경 갱신을 적용했다. 추가 요청에 따라 일정·기간 상세에서 홈 화면에 위젯을 추가하는 동선과 크기별 추가 미리보기도 적용했다. 새로고침과 30분 주기는 유지하며 정밀 갱신 실기기 검증은 후속 범위다. **2026-09-21 요청 후 빌드·단위 테스트 46개·Lint를 통과했다. 에뮬레이터 검수 범위와 API 35/37의 시스템 초기화 중 시작·응답 지연 기록은 최신 위젯 기록을 따른다.**

2026-09-21 최신 크기 수정: **일반 4×2·기간 요약 4×1**로 기본 배치를 변경했다. 공간 하한은 단일 250×180dp·요약 250×64dp다. 요약의 공통 제목 제거·문자 폭에 따른 열 배분·8dp 세로 여백, 작은 단일 위젯의 8dp 세로 여백, 소스별 안내 및 미리보기 크기도 함께 수정했다. **이 후속 변경에는 이전 빌드·46개 테스트 통과 결과를 적용하지 않는다. 빌드·Lint·단위 테스트·새 APK 화면 확인은 아직 수행하지 않았다.** 기존 설치 앱은 이 변경 전 코드다.

**사용자의 명시적 요청 전에는 빌드·Lint·단위 테스트를 실행하지 않는다.** 이 규칙은 다른 PC에서도 유지한다.

최근 위젯 변경은 코드 검증과 일부 실제 화면·추가·취소·상세 동선을 검수했다. Lint는 오류 0개, 경고 108개, 힌트 4개다. 모든 OS·런처·팔레트·기존 설치 업데이트·절전 조건이 검증된 것은 아니다. 전체 일정의 후속 간격·입력·애니메이션도 전체 조건에 대한 검수는 남아 있다.

다음 추가 검수에서는 아래의 미검증 조건을 확인한다. 코드 변경 후 재검증은 사용자 요청 시 진행한다.

1. 기본 코드 검증: `./gradlew testDebugUnitTest assembleDebug lintDebug` (Windows는 `gradlew.bat`). 기존 경고와 새 문제를 구분한다.
2. 새 APK의 실제 화면: 밝게/어둡게·320dp·큰 글자·긴 한/영 제목·빈 상태·검색·선택·상세 애니메이션.
3. 기존 네 위젯이 설치된 상태에서 업데이트: ID·선택 일정·표시 모드·크기 유지, 재설정 저장/취소.
4. 다섯 신규 진입의 기본 내용과 단일 4×2·요약 4×1 배치, 새 일정 provider 갱신, 기간 요약 크기 부족과 확대 후 복구, 설정 미리보기와 설치 결과 일치.
5. 일정 조회 오류/재시도·선택 일정 삭제·날짜 경계·반복, 접근성 및 실제 런처별 동작.

## 새 환경 준비

- Android Studio, Android SDK 36, JDK 17 toolchain을 준비한다. Gradle Wrapper와 프로젝트 설정은 저장소에 포함되어 있다.
- SDK 경로·Gradle의 로컬 Java 경로·에뮬레이터 선택은 새 PC에서 설정한다. 기존 PC의 절대 경로나 생성 캐시를 옮길 필요는 없다.
- `local.properties`, 서명 키, `keystore.properties`는 Git에 포함하지 않는다. 출시 서명이 필요한 작업에서만 별도로 준비한다.
- 앱에 필요한 위젯 XML/PNG와 PNG 생성 스크립트, 스토어 등록용 `store-assets/`의 아이콘·배너는 보존했다. 위젯 PNG 재생성은 일반 빌드에 필요하지 않으며 Pillow와 한글 지원 산세리프 글꼴이 있을 때 수행한다.

## 이번 정리 범위

QA PNG·화면 XML·비교 이미지·결과 JSON, PC 경로가 고정된 촬영/합성 스크립트, Python/Kotlin/Gradle 캐시·앱 빌드 출력, IDE 기기 선택·미리보기 확대 기록, 더 이상 참조하지 않는 이전 위젯 PNG를 제거했다. 디자인 결정·검수 범위·미검증 조건은 텍스트로 남겼다.

이전에 커밋된 QA 파일은 `8986d02`의 `design/qa`, `design/qa-v2`, `design/qa-flow`, `design/qa-period-hint`에서 확인할 수 있다. Git 이력은 재작성하지 않았다. 폐기한 미커밋 `qa-affordance` 캡처는 최종 기준이나 검수 증거로 사용하지 않는다.

앱에서 바로 위젯을 추가하는 pin 기능은 구현했고, 정밀 갱신 개선은 후속 작업이다. 종료된 날짜만 남으면 자동 선택 후보 없음으로 처리하는 변경과 시간 변경 방송 갱신은 2026-09-21에 반영했으며 검증 대기다. DB 스키마·기존 일정·앱 출시 버전은 이번 개편으로 변경하지 않았다.

2026-09-21 Galaxy 크기 보정: 연결된 기기의 설치 APK에도 `targetCellHeight=2`가 들어 있었지만 One UI Home은 내 일정 위젯을 4×3(375×323dp)으로 배치했다. 런처에 180dp를 선언한 설정을 보완해 배치용 높이는 단일 110dp·요약 40dp로 분리했다. 실제 콘텐츠 하한 180dp·64dp와 내용 측정은 유지한다. 최신 보정 APK의 빌드·설치·재배치 확인은 아직 수행하지 않았다. 기존 설치 위젯의 크기는 호스트가 보관하므로 새로 추가하거나 수동 리사이즈하여 확인한다.

2026-09-21 최신 단일 위젯 배치: 시간과 상태를 같은 행으로 묶고, 눈금 아래 시작·종료 시각/날짜를 기본 구성으로 포함했다. 간격은 숫자→눈금 8dp·눈금→라벨 4dp다. 실제 콘텐츠 하한은 180→160dp로 조정하고 전체 텍스트 측정으로 표시 여부를 판단한다. 런처 배치 힌트 110/40dp는 유지한다. 한/영 상태 문구 순서, D-day/D+ 예외, 눈금 숨김 시 종료 정보 보존, 개인 날짜 일정의 범위 라벨과 미리보기를 반영했다. **이번 변경도 빌드·Lint·단위 테스트·새 APK 실행 검수 전**이다.

2026-09-21 최신 아이콘·시작 화면: 배경을 Clay 강조색으로 변경하고 적응형/호환/스토어용 로컬 아이콘에 반영했다. 스플래시는 밝기별 앱 배경, 최대 360ms 로고 정렬, 200ms 진입·탭 즉시 완료·애니메이션 비활성화 및 생명주기 정리를 적용했다. 빌드·Lint·단위 테스트·설치 검수 전이며 [브랜드·시작 기록](QA_BRAND_LAUNCH_2026-09-21.md)을 따른다. 아이콘 재생성은 선택적 스크립트 `generate_brand_icons.py`와 Pillow/resvg-py로 수행한다.
