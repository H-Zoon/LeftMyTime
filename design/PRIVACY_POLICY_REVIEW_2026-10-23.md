# 개인정보처리방침 최소 개정 검토 — 2026-10-29

## 적용 범위

사용자의 후속 선택에 따라 10월 23일에 작성한 14개 항목의 확장 문안을 기존 11개 항목을 유지하는 최소 개정으로 바꿨다. 기존 `docs/privacy.html`을 기준으로 PointHome 설명·정책 링크와 충돌하는 문구만 수정했으며, 시행일은 사용자가 지정한 2026년 10월 23일을 유지했다.

- 방침 본문 원본: `docs/privacy.html`
- 읽기용 본문: `PRIVACY_POLICY_2026-10-23.md`
- Google Sites 붙여넣기용: `PRIVACY_POLICY_2026-10-23.txt`
- Markdown·일반 텍스트는 같은 HTML 원본에서 생성했다.
- Google Sites는 편집하지 않았다. 후속 요청으로 Firebase Hosting의 `/privacy.html`에 같은 본문을 게시하고 앱의 방침 URL도 변경했다. 생성·배포 방법은 `hosting/README.md`를 따른다.
- APK 설치와 앱 화면 검수는 하지 않았다. 앱 내 URL 변경은 새 빌드 배포 후 반영된다.

## 반영한 사실

1. 회원·출금 계좌정보는 아바티만 처리하고 개발자는 조회·수신하지 않는다고 사용자가 확인했다.
2. PointHome의 광고 ID 수집 사실은 사용자 설명과 [아바티 공개 방침](https://www.avatye.com/policy/privacy)에 근거했다. 광고식별자의 저장 여부·구체적인 보유기간은 확인되지 않았으므로 ‘저장하지 않음’이나 임의의 보유기간을 기재하지 않았다.
3. 광고 ID·기기정보·이용기록·행태정보 등의 처리 개요, 아바티 방침 링크, 해당 서비스의 삭제·문의 절차를 추가했다.
4. ‘광고 ID 수집과 광고 개인화 비활성화’의 적용 범위를 Firebase Analytics로 한정했다. PointHome·광고 서비스에 동일하게 적용된다고 설명하지 않는다.
5. 로컬 원본은 이미 통계·오류·성능 자동 수집을 설명한다. `AppTelemetry.kt`에서 Analytics·Crashlytics 수집 활성화를 확인했고 공개 Google Sites의 과거 선택형 안내 대신 복사할 본문에도 이를 유지했다. 자동 수집 동작 자체를 바꾸지는 않았다.
6. ‘계정 가입 없이 이용’은 TimeLeft의 기본 일정·위젯·집중 기능으로 범위를 명확히 했다. PointHome의 회원 절차와 구분한다.
7. 초기화는 `App.kt`와 `PointHomeIntegration.kt`의 실행 순서를 근거로 앱 실행 시 이루어진다고 설명했다. 초기화만으로 어떤 정보가 실제 전송되는지를 검증했다고 쓰지 않았다.

## 확인 범위의 정리

아바티가 직접 처리하는 회원정보·출금정보의 내부 보관·삭제·클라우드 운영을 우리 처리로 재분류하거나 모든 보유기간·처리국가를 독자적으로 조사하여 재기재하는 방식은 적용하지 않았다. 해당 사업자의 공식 정책과 서비스 안내를 연결했다. 아바티 또는 모든 광고 사업자를 일괄 수탁자로 분류하지 않았다.

다만 우리 앱에 포함된 SDK가 실제 수집·전송하는 데이터는 Play 데이터 보안 신고 범위에 포함된다. 공급사의 공식 SDK 데이터 보안 안내를 근거로 작성할 수 있으며, 저장 여부가 불명확하다고 ‘수집 없음’으로 신고할 수는 없다. 이 문안 작성으로 Play Console 신고가 완료되거나 별도 동의 요건이 충족된 것은 아니다.

- [Google Play 데이터 보안 기준](https://support.google.com/googleplay/android-developer/answer/10787469?hl=ko): 기기 밖 전송과 SDK 처리를 포함하며 저장과 수집을 구분한다.
- [아바티 개인정보처리방침](https://www.avatye.com/policy/privacy): PointHome 기능별 정보, 자동 기기·광고식별자·행태정보, 일반 보유·파기 기준 및 문의처.

## 검증 결과와 남은 반영

- 로컬 소스·공식 방침 대조, HTML 구조·문서 번호·공백·일반 텍스트와의 내용 일관성을 정적으로 확인했다.
- 미확인 보유기간·국외 처리 지역·계약 관계를 추가로 확정하지 않았다.
- 빌드·Lint·단위/계측 테스트·재설치·화면 검수·SDK 통신 검증은 사용자 요청 전이라 실행하지 않았다.
- Google Sites와 Play Console은 변경하지 않았다. Firebase Hosting 외부 게시와 앱 코드의 URL 변경을 반영하며, 앱 새 빌드 반영과 Play Console의 방침 URL 변경은 남아 있다.
- 리워드 광고성 알림 고지·동의·운영 문제는 이 문구 수정과 별개이며 구현이나 발송 설정을 변경하지 않았다.
