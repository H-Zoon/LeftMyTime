# 집중 시작 동선 정리 — 2026-10-29

사용자 요청: 홈의 15/25/50분·직접 입력을 없애고 ‘집중 바로 시작’ → 집중 화면의 시간 다이얼 → ‘시작’으로 구성한다. 추가 요청에 따라 집중 기록도 집중 화면 내부로 옮긴다.

## 반영

| 위치 | 이전 | 변경 |
| --- | --- | --- |
| 홈, 집중 없음 | 제목·분 선택 3개·직접 입력·집중 기록 | ‘집중 바로 시작’ 진입 하나 |
| 홈, 진행/일시정지 집중 있음 | 기존 집중 열기·기록 | 기존 집중 열기 하나 |
| 집중 준비 화면 | 없음 | 선택한 총시간·시/분 휠 다이얼·시작·집중 기록 |
| 시간 선택 | 홈에서 즉시 시작 또는 숫자 입력 대화상자 | 집중 화면에서 선택, 시작으로 확정 |
| 집중 기록 복귀 | 홈/진행 집중 | 준비 화면에서 열었으면 선택값을 유지해 준비 화면으로 복귀, 진행 집중에서 열었으면 기존 집중 화면으로 복귀 |

기본 25분, 기존 1~1,440분 범위다. 0시간에서는 분을 1~59로 제한하며 24시간에서는 분을 0으로 고정한다. 휠은 정지 후 중앙 행에 맞추며 움직이는 동안 시작을 막는다. 준비 화면 진입·시간 선택·취소·기록 열기는 세션을 생성하지 않는다. 새 세션이 만들어지면 같은 `FocusActivity`에서 기존 진행 화면을 표시한다.

준비 중에 기존 진행/일시정지 집중을 발견하면 해당 집중으로 연결한다. 이는 시작 저장 중 Activity가 재생성된 경우의 회복 경로도 제공한다. 기존 `FocusViewModel.start`와 `FocusCoordinator`의 중복 실행 방지·계산·저장·완료 알림·`FocusStarted` 이벤트를 재사용한다. DB 스키마, 사용자 설정 키, 출시 버전, 알림 권한 흐름을 변경하지 않는다. 홈의 기존 FocusViewModel 수집도 유지하여 만료 집중 갱신 동작을 보존한다.

`TimeLeftTheme`, `TimeLeftTopAppBar`, `TimeLeftInlineButton`, `Spacing`, `LayoutTokens`, 기존 시간 포맷터와 타이포그래피를 재사용한다. 휠은 얇은 구분선 두 개와 중앙 선택 숫자로 표현한다. 행 높이는 최소 48dp이며 큰 글자에서는 숫자 크기에 맞춰 확대하고 화면 전체를 세로 스크롤한다. 각 휠에 이름·현재 값·조절 가능한 범위·비활성 상태와 접근성 값 변경 동작을 제공한다. 새 팔레트·카드·그라데이션·진행 링은 추가하지 않는다.

## 정적 확인

- 홈 진입 콜백의 분 인자를 제거하고 MainActivity에서 `FocusActivity.setupIntent`로 연결했다. 기존 세션/알림/위젯의 `FocusActivity.intent(id)` 경로는 유지했다. 문장 입력 경로는 같은 날 후속 사용자 요청으로 제거했다.
- 홈 `QuickFocusSection`에는 기록 링크·고정 시간·직접 입력 대화상자가 없다. 기록은 준비 및 기존 진행/완료 화면 안에서 접근한다.
- 선택 시간·현재 세션 ID·기록 표시 상태는 `rememberSaveable`로 보존한다. 준비 intent를 유지하여 저장 상태보다 늦게 시작된 활성 집중도 데이터 로드 후 발견한다.
- 시/분 경계와 24시간 상한, 휠 스냅/선택값 연결, 세션 생성의 단일 경로, 한·영 리소스와 변경 공백을 코드로 검토했다. 로컬에 저장된 Compose Foundation 1.6.8 AAR에서 사용하는 스냅 API를 확인했다.
- debug `DesignGallery`는 제품의 `FocusSetupScreen`을 재사용한다. `focus-setup`, `focus-setup-min`, `focus-setup-max`, `focus-setup-busy`, `focus-setup-loading`, `focus-setup-failed`, `focus-setup-error`와 기존 밝음/어두움·320dp/큰 글자 Preview를 제공한다. 갤러리의 시작/기록 콜백은 사용자 데이터를 변경하지 않는다.

## 미검증과 다음 확인

사용자 명시 요청 전이므로 빌드·Lint·단위/계측 테스트·설치·실화면 검수를 실행하지 않았다. 설치된 앱에는 이 변경이 없으며 위 정적 확인과 Preview 추가를 시각 검수 완료로 취급하지 않는다. 기준 화면 변경 전후 캡처도 아직 없으며 다음 실행 검수에서 Git 제외 `design/qa-focus-setup-2026-10-29/`에 남긴다.

- 밝음/어두움, A/시간 보드 홈, 320dp와 큰 글자, 긴 진행 집중 제목, 집중 없음·기록 없음.
- 1분·25분·59분→1시간·23시간59분→24시간, 시간 변경 시 분 보정, 빠른 플릭/끝 경계/행 터치/접근성 값 변경과 선택 숫자·실제 시작 길이 일치.
- 홈 진입/뒤로 가기/기록 왕복만으로 새 세션이 생기지 않음. 선택 후 회전·백그라운드·프로세스 복원에서 값 유지.
- 시작 연속 터치, 저장 중 회전/종료/복원, 조회·저장 실패 후 재시도, 기존 실행/일시정지 집중 발견 시 복귀, 실제 DB 레코드 한 개 생성.
- 시작 후 남은 시간·일시정지/재개·중단·기록·화면 켜짐·완료 알림, 자정 전후 24시간 세션, 기존 위젯/알림에서 집중 열기 회귀.
- 기록에서 시스템/상단 뒤로 가기, 종료된 집중 직접 열기와 준비 화면의 구분, TalkBack 이름·값·조절·포커스 및 휠 최소 터치 영역.

사용자가 최종 검증을 요청하면 프로젝트 기본 `./gradlew testDebugUnitTest assembleDebug lintDebug`와 위 실행 검수를 포함한다.
