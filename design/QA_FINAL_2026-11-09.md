# UI 변경 최종 검수 — 2026-11-08~09

2026-11-09 후속: 사용자 요청으로 개인정보처리방침을 Firebase Hosting `timeleft-f83ba`에 배포했다. 공개 HTTP 200·로컬 게시본 바이트 일치, 이야기 저장/문장 입력 옛 안내 제거와 리워드 알림 안내 반영을 확인했다. 다른 공개 3파일은 변경되지 않았다. 아래의 공개 방침 게시 대기는 검수 당시 기록이며 이제 해결됐다. 배포 후 Android WebView 재검수는 하지 않았다. [배포 검증 결과](../hosting/privacy-deployment-2026-11-09.json)를 따른다.

사용자 요청: “검수 진행”, “중단된 부분부터 마저 진행”. 기존 홈·공통 상세·설정 정리, 이야기 기능/저장 기록 제거와 함께 아직 보지 않은 보조 화면을 검수했다.

상태: **Debug 빌드·단위/Lint·계측 및 아래 범위의 새 APK 가상머신 검수 완료. 발견한 테마 오류·백업 문구·SDK 스크롤 가림을 수정 후 재확인했다.** 아래 결과는 명시한 조건에 한정한다. 모든 기기·상태·출시 버전의 검수 완료를 뜻하지 않는다.

## 환경과 증거

- 읽기 전용 Pixel 10 Pro XL AVD, Android 17/API 37.2·16KB 페이지·소프트웨어 렌더러. 연결된 실제 휴대전화는 조작하지 않았다.
- 기본 1344×2992px/480dpi(448dp), 밀도 672dpi로 320dp. 한/영, 밝게/어둡게, 글자 1.0/1.5배와 달력 세 자리 일수의 2.0배를 확인했다. 모든 화면의 모든 조합을 확인한 것은 아니다.
- 실제 화면을 공유하는 debug `DesignGallery`의 고정 예시와, 가상머신에서 직접 입력한 일정 `909001`·`909002`를 구분했다. 예시 화면은 실제 저장/수신 동작의 증거로 사용하지 않았다.
- 로그·원본 PNG·UI hierarchy·JSON 결과는 Git 제외 `design/qa-final-2026-11-08/`에 보존한다. 이전 6.8 캡처·생성 시안과 구분되는 새 Debug APK 실행 캡처다.
- 버전 6.8(25)은 변경하지 않았다. Release 서명·배포·커밋·push·공개 웹 게시·FCM 캠페인 변경은 하지 않았다.

## 이야기 기록 삭제와 설정 보존

이전 형식의 `story_library.xml`에 즐겨찾기와 읽은 시각 두 항목을 넣고 `.bak`도 만든 뒤 앱 프로세스를 재시작했다. 전용 파일 둘 다 없어졌고, 별도 설정 파일·기본 정렬 값·일정 DB의 두 행은 그대로였다. `story-cleanup-result.json`을 따른다. 처음 자동화의 `adb exec-out` 파일 부재 판정은 잘못된 종료 코드를 읽어 수정했고, 실제 `test -f`와 재실행으로 결과를 확인했다.

이는 현 Debug 앱에 이전 형식 파일을 만든 검수다. 서명이 다른 기존 Release APK 위에 직접 업데이트한 결과나 실제 사용자 기기의 삭제 완료로 확대하지 않는다. 삭제 실패 후 재시도·운영체제의 파일 복원은 별도 미검증이다.

리워드 상세를 열고 회전·상단 뒤로가기·시스템 뒤로가기를 수행했다. 메인 설정의 보이는 텍스트/좌표가 복원됐고, 수신 선택·선택 시각·고지 버전의 전후 값도 같았다(이 기기의 기본 수신 꺼짐 상태). 켜짐/차단·읽기 실패 등의 표시 예시는 별도 debug fixture이며 실제 구독/수신 검증으로 취급하지 않는다.

## 검수 중 수정

1. **테마 오류 설명 누락:** 기존 재시도 버튼만 있던 첫 화면에 기존 `theme_preview_error`를 함께 제공했다. 같은 EN·어둡게·320dp·1.5배에서 설명과 재시도를 재확인했다. 기존 본문/보조색/간격·48dp 토큰을 재사용했다.
2. **제거된 기능의 안내 잔여:** 백업 범위의 ‘이야기 즐겨찾기 제외’ 문구를 한/영에서 제거했다. 시간·일정·집중 기록이나 백업 형식은 바꾸지 않았다.
3. **미사용 문자열:** 설정 정리로 사용처가 없어진 4개 키를 한/영에서 제거했다.
4. **SDK 가림:** 실제 320dp·1.5배의 홈을 내리면 캐릭터가 눈금과 종료 시각을 덮었다. 공개 SDK 표시/숨김 API로 본문 스크롤 중 숨기고 맨 위에서 복원하도록 보완했다. SDK 캐릭터·애니메이션·저장 위치·리워드 동작과 영구 설정 키를 유지한다. 생성 콜백·Activity 복귀에 현재 상태를 다시 적용하며, 인트로도 실제 표시 가능한 맨 위 상태를 확인한다. 같은 320dp·시스템 글자 1.5배에서 맨 위 노출 → 스크롤 시 숨김 → 집중 화면 왕복 후 숨김 유지 → 맨 위 복귀 시 같은 좌표로 재노출을 확인했다(95~98). 전체 일정에서도 맨 위 노출/스크롤 숨김을 확인했다(102~103). `sdk-visibility-result.json`·`sdk-all-schedules-result.json`을 따른다.

## 남은 문제·범위

- **공개 방침 게시 대기:** 앱은 공개 웹 방침을 읽으므로 41 캡처에는 이전 이야기 저장 안내가 보인다. 로컬 `docs/privacy.html`·Hosting 소스와 Markdown/일반 텍스트는 맞췄지만 공개 게시하지 않았다. 앱 내 표시까지 최신으로 바뀌었다고 쓰지 않는다.
- **후속 디자인 후보:** 작은 화면·큰 영어 글자에서 위젯 설정의 긴 설명이 미리보기보다 앞서며 첫 화면에 결과가 보이지 않을 수 있다(12·13). 스크롤로 접근할 수 있어 차단 결함과 구분했다. 백업·캘린더·집중의 기본 pill 버튼도 기존 편집 저장과 모양이 달라 공통 행동 스타일 정리 후보로 남긴다.
- 실제 휴대전화·다른 Android 버전·One UI 등 다른 런처·XML Chronometer 전달의 실제 음수/장시간/배터리·정확 알람 허용/거부별 수신·실제 FCM·SDK 서비스·계정 캘린더 가져오기·서명 Release 업데이트는 미검증이다.
- TalkBack/키보드의 실제 읽기 순서·포커스 전체, 모든 색상/화면 구성과 2배 글자의 모든 화면, 프로세스 사망 후 모든 화면 복원·알 수 없는 기존 설정값의 전체 조합은 미검증이다.

확인하지 않은 조건을 통과로 확대하지 않았다. 실제 검수와 수정 후 재확인이 끝난 범위는 위 표를 따르며, 공개 게시·실기기/다른 런처·서명 업데이트는 후속 작업이다.
