# 스플래시 · 바깥 윤곽 그리기와 안쪽 원 회전

후속 검증(2026-09-27): 사용자 승인으로 빌드·테스트·Lint를 통과했고 API31/37 서명 release의 런처 진입을 녹화했다. 최종 로고·밝기·진입과 모션 배율0 상태는 확인했으나, **바깥 선 감김·짧은 선 등장 중간 프레임은 확보하지 못했다.** 아래 미빌드 기록은 구현 당시 상태이고 리소스 GIF는 여전히 실제 모션의 증명이 아니다. [최종 출시 QA](QA_RELEASE_2026-09-27.md)의 미확인 조건을 따른다.

사용자 요청: 각 원이 돌아가는 느낌 등 역동적인 스플래시 애니메이션 적용.

최신 피드백: 비원형인 바깥 윤곽의 통째 회전과 그대로 남아 있는 왼쪽 직선이 어색하다. 바깥 윤곽은 왼쪽부터 감기며 완성하고, 직선도 왼쪽부터 등장하도록 변경한다. 아래는 이 피드백을 반영한 최종 구현이다.

## 구현

- 기존 정돈된 심볼과 밝기별 Clay 색상·안전 영역을 유지했다. 별도의 로딩 화면이나 새 로고를 만들지 않았다.
- 바깥 윤곽의 회전 그룹과 애니메이터를 제거했다. 기존 단일 열린 경로의 `trimPathEnd`를0→1로 바꿔 왼쪽 위 x94 시작점→위 가로선→오른쪽·아래 원호→왼쪽 끝 순으로560ms 동안 완성한다. 도형의 위치·선 굵기·회전 각도는 그대로이며 실제 로딩 진행률을 표시하는 동작이 아니다.
- 두 짧은 가로선을 각각 x94를 기준으로 한 그룹에 넣어 가로 크기0→1로 등장시킨다(위260ms, 아래320ms). 세로 크기는1이고, 최종 경로의 잘린 끝 형태를 유지한다. 오른쪽 경계를 임시로 가로 압축하는 방식이며 경로를 바꾸거나 다른 두께의 선으로 대체하지 않는다. 기존 단순 페이드 파일은 제거했다.
- 안쪽 원은 독립 그룹의 +160→0도, 560ms 반시계 방향 회전을 유지한다. 바깥 윤곽 그리기·가로선 등장·안쪽 원은 기존 `ease_out_cubic`을 공유한다.
- 전체 크기는0.94→1, 중앙 V는0.8→1(400ms)로 자연스럽게 커진다. 안쪽 원·V의 투명도도 같은 곡선으로1에 도달한다. 모든 애니메이터는 지연 없이 시작하며 종료 길이로 리듬을 구분한다. 경로 그리기·회전·크기·투명도 모두 반복하지 않는다.
- 최장 길이는 `values/splash_tokens.xml`의 `splash_icon_motion_duration`(560ms)이며 바깥 윤곽·안쪽 원·전체 크기·Android12+ 테마가 함께 참조한다. 기존 360ms 모션 제한은 이번 명시적 요청에 맞춰 변경했다.
- 기존 `SplashExitTransition`의200ms 사라짐·8dp 이동·탭으로 즉시 진입·비활성화 및 화면 종료 정리를 재사용한다. `MainActivity`나 데이터 로딩 로직을 변경하지 않았다. 최소 노출 시간·애니메이션 종료를 기다리는 조건은 추가하지 않았다.
- Android12+ 시스템 AnimatedVectorDrawable에 적용한다. Android8–11은 현재 정적 로고와 종료 전환을 유지한다. [AndroidX 공식 문서](https://developer.android.com/reference/androidx/core/splashscreen/SplashScreen)는 API31 미만 시작 화면에서 Animated Vector Drawable을 지원하지 않는다고 명시한다.
- 앱이 일찍 준비되면560ms 전에 스플래시가 사라질 수 있다. [Android 스플래시 지침](https://developer.android.com/develop/ui/views/launch/splash-screen)의 일찍 건너뛸 수 있는 동작에 맞춘다. 이미 실행 중인 앱으로 돌아오는 경우에 회전을 다시 넣지 않는다.

## 리소스 검토와 시각 참고

- XML 파싱, 각 애니메이션 대상의 그룹/경로 연결, 총 길이560ms, 최종 경로 끝1·회전0·크기1·투명도1, 반복 없음, 정적 심볼과 최종 도형 일치를 검토했다. 바깥 회전·가로선 페이드의 삭제된 리소스 참조가 남지 않았는지도 확인했다.
- 실제 벡터와 애니메이터 XML, 공통 감속 곡선을 읽어0/100/260/560ms 프레임과 GIF를 다시 생성했다. 바깥 경로 그리기는 직선162와 반지름150의270도 원호 길이로 SVG 대시를 계산한 근사이며 Android PathMeasure의 실행 결과는 아니다. 밝게/어둡게 표본에서 왼쪽 시작·시계 방향 그리기·최종 정렬을 육안 확인했다. 이 변환은 Android 렌더러나 기기 타이밍을 재현한 실행 검수가 아니다.

## 미검증과 다음 확인

- **빌드·Lint·단위 테스트·새 APK 설치·Android 실제 실행 검수는 하지 않았다.** 사용자 명시적 요청 시 진행한다. 현재 설치 앱은 이번 아이콘/배경/모션 수정 전 버전이다.
- Android12+ 차가운/따뜻한 시작과 매우 빠른 시작, 이전 버전 정적 표시, 밝게/어둡게, 시스템 애니메이션 배율0/1/큰 값, 종료 전환 중 탭·홈 이동·뒤로가기·회전, 권한 변경에 의한 프로세스 재시작, 작은 화면·TalkBack을 확인한다.
- 시작 성능이나 실제 부드러움을 검증 완료로 주장하지 않는다. 긴 제목·빈 일정·글자 배율은 이번 벡터 모션과 무관하므로 해당 화면 검수를 확장하지 않았다.
