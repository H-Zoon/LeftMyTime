# 시간 범위별 이야기 기능 제거

2026-11-09 후속: 이전 형식의 이야기 즐겨찾기/읽은 시각과 .bak 파일을 현재 Debug 앱에 만들고 재시작해 둘 다 삭제됨을 확인했다. 다른 설정 파일과 일정 DB2행·정렬 값은 유지됐다. 백업의 옛 이야기 제외 안내도 제거 후 확인했다. 실제 사용자 기기·서명 Release 업데이트 검증은 아니며 [최종 검수 범위와 남은 공개 방침 게시](QA_FINAL_2026-11-09.md)를 따른다.

날짜: 2026-11-08. 사용자 요청: “시간 범위에 따른 문구기능 제거”, “기존 기기의 저장 기록도 모두 삭제”.

상태: **소스 반영 완료. 빌드·Lint·단위/계측 테스트·새 APK 설치·기록 삭제 실행·시각 검수는 미실행.** 설치된 기존 6.8 앱에는 이 변경이 반영되지 않았다.

## 변경 범위

- 공통 `TimeDetailContent`에서 ‘이만큼의 시간’과 기간에 따른 이야기 선택을 제거했다. 오늘·달·년·주·분기·개인 일정·위젯에서 연 앱 상세에 동일하게 적용한다.
- 이야기 전환·저장/해제·보관함·외부 출처 진입과 설정의 보관함 행, Manifest의 전용 Activity를 제거했다.
- `stories`의 전용 Kotlin 파일 4개, 사용처가 사라진 `Motion.StoryChangeMs`, 한/영 각 96개 문자열, 이야기 전용 debug 사례 9개를 제거했다.
- 기존 `TimeDetailContent`, `RemainingTimeText`, `TimeRuler`, `TimeDetailDisclosure`와 테마를 유지한다. 큰 남은 시간·눈금·현재 일차·접힌 기간 정보·미리보기는 그대로 사용한다. 대체 응원 문구나 새 표면을 추가하지 않았다.
- 로컬 스토어 설명과 개인정보처리방침의 현행 저장 항목을 맞췄다. 공개 웹·Play Console 게시나 버전 변경은 하지 않았다.

## 기존 기록 삭제

이야기는 Room이나 일정 백업 JSON에 저장되지 않고 `story_library` SharedPreferences 파일의 `favorites`와 `seen_<id>`에만 저장돼 있었다. `App.onCreate()`에서 Android `deleteSharedPreferences("story_library")`로 해당 전용 파일 전체를 삭제한다. 별도 완료 플래그 없이 프로세스가 시작될 때 다시 시도하므로 삭제 실패나 운영체제의 이전 파일 복원 뒤에도 다음 시작 시 정리한다. 실패는 개인정보 없는 경고로만 남긴다.

이 삭제는 새 버전이 설치된 기기에서 앱 프로세스가 시작될 때 적용된다. 현재 작업에서 사용자의 실제 기기에 접속하거나 기존 기록을 삭제한 것은 아니다. 일정·집중 기록·저장한 일정·설정·위젯 데이터와 DB 스키마·일정 백업 형식은 변경하지 않는다.

## 확인과 남은 검증

제거한 심볼·리소스·Activity·콜백의 잔여 참조가 `app/src`에 없음을 확인했다. 한/영 XML 파싱·키 중복 없음·포맷 인자 일치, Manifest XML·스토어 JSON 파싱, `git diff --check`를 통과했다. 삭제 호출의 대상은 이야기 전용 파일 하나이며 이전 저장소 정의와 대조했다. 빌드나 실행 검증을 대신하지 않는다.

명시적인 최종 검증 요청 시 기존 전체 변경의 `./gradlew testDebugUnitTest assembleDebug lintDebug`와 함께 다음을 확인한다.

1. 이전 버전에 즐겨찾기·읽음 기록을 만든 뒤 업데이트한다. 첫 프로세스 시작 후 이야기 전용 파일과 기록이 없어지고 재시작 시 오류가 없는지 확인한다. 일정·집중 기록·저장한 일정·설정은 전후 동일해야 한다.
2. 신규 설치와 이야기 파일이 없는 업데이트, 삭제 실패 후 다음 프로세스 시작의 재시도, 이전 파일이 복원된 뒤 정리를 확인한다.
3. 홈에서 연 모든 기간·개인 일정 상세, 주/분기, 위젯에서 연 상세와 설정에 이야기·보관함·빈 자리·남은 구분선이 없는지 확인한다. 기존 남은 시간·눈금 탐색·기간 정보는 정상 동작해야 한다.
4. 밝게/어둡게·작은 화면·큰 글자·긴 제목·빈 홈/전체 목록을 확인하고 같은 조건의 전후 캡처를 Git 제외 `design/qa-*/`에 남긴다. 이전 상세 시안의 이야기 행은 현재 목표에서 제외한다.

현재 새 실행 캡처는 없다. 이전 설치 앱 분석과 소스 변경을 구분하며, 위 조건을 통과했다고 확대하지 않는다. 이전 콘텐츠·기능 문서는 과거 기록으로 보존한다.
