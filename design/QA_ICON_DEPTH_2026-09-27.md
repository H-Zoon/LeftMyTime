# 정돈한 아이콘 일괄 적용 · 배경 명암

후속 검증(2026-09-27): 사용자 승인 후 debug/release 빌드·테스트·Lint·서명 검사와 신규 release 설치의 실제 런처 표시를 확인했다. 아래 미빌드 기록은 구현 당시 상태다. 최신 범위와 제조사 실기기 미검증은 [최종 출시 QA](QA_RELEASE_2026-09-27.md)를 따른다.

사용자 요청: 지금까지 작업을 먼저 커밋하고, 정돈한 디자인을 앱에 일괄 적용하며 평평한 배경을 그라데이션 등으로 개선.

## 커밋과 범위

- 위젯 초 표시와 기존 심볼 정돈까지 `01e9d6a`에 먼저 커밋했다. 이 문서의 배경 개선은 그 이후 변경이며 아직 커밋하지 않았다.
- 이번 배경은 대화에서 다루던 **앱 아이콘 배경**이다. 앱 본문·위젯·시작 화면 전체 배경 변경으로 확장하지 않는다.

## 적용

- 기존 Clay와 정돈된 흰색 심볼을 유지하고 배경만 좌상단 `#C45B40`, 중앙 `#B5482D`, 우하단 `#9E3926`으로 이어지게 했다. 중간 경계 없는 선형 그라데이션이며 그림자·광택·반복 움직임은 추가하지 않았다.
- 일반/원형 적응형 아이콘 모두 `drawable/ic_launcher_background.xml`을 참조한다. 색상은 기존 `values/ic_launcher_background.xml`에서 관리한다. 기본 Clay 값은 스플래시 단색 로고도 공유하므로 그대로 유지한다.
- 기존 `generate_brand_icons.py`가 Android 배경의 색상·방향을 읽어 스토어 PNG2개, 일반/원형 WebP10개를 생성한다. 투명 전경 PNG5개는 정돈된 벡터와 같은 상태로 유지된다. 래스터용 팔레트를 따로 복사하지 않는다.
- Manifest의 기본/원형 아이콘 → 적응형 배경·전경 연결을 확인했다. Android 기본/v27/v31 시작 테마 → 정적/애니메이션 스플래시 → 정돈한 심볼 연결을 확인했다. 프로젝트 안에서 이전 도형을 쓰는 다른 제품 리소스는 발견하지 않았다.
- 정돈한 심볼의 안전 영역·크기·애니메이션은 변경하지 않았다. 사용자 데이터·설정·위젯 기능 변경은 없다.

## 정적 확인

- Android 배경·전경·적응형 리소스의 XML 파싱과 참조, 동일한 세 벡터 도형, 기존 애니메이션 대상 연결을 검토했다.
- 생성 이미지 크기·스토어 두 사본 일치·배경 불투명도·좌상단→우하단 밝기 감소를 확인했다. 작은 호환 이미지와 밝게/어둡게 비교에서 심볼과 배경의 분리, 외곽 잘림을 육안 확인했다.
- 아래는 실제 생성한 이미지의 정적 비교다. 마스크 비교는 기기 런처 캡처가 아니다.

## 남은 확인

- 사용자 지시에 따라 빌드·Lint·단위 테스트·APK 설치는 실행하지 않았다. 현재 설치 앱은 아이콘 정돈과 이번 배경 개선 전 버전이다.
- 최종 요청 시 Android 런처별 마스크·배경 크롭·캐시 갱신, 작은 런처 아이콘, 밝은/어두운 배경, Android8–11/12+ 실제 시작 화면 전환을 확인한다. 런처가 배경을 잘라 쓰므로 기기별 보이는 명암 범위가 다를 수 있다.
- 큰 글자·긴 제목·빈 일정은 이번 이미지 변경과 무관하며 기존 검수 범위를 확장하지 않는다. 스토어 게시·배포는 수행하지 않았다.
